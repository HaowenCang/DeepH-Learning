### 3.2 表示约定的独立数学复算

审计未沿用主 agent 的预检结果，而是独立生成固定随机对象并构造反例。

1. 以 SciPy 1.18.0 的 DLMF 型 `sph_harm_y` 点值为交叉参照，在 200 个固定随机单位向量上逐点复算约定中的复—实映射。按 \(m=-\ell,\ldots,\ell\) 排序，ℓ=1 和 ℓ=2 的最大绝对误差分别为 \(2.989\times10^{-16}\) 与 \(7.005\times10^{-16}\)。这确认 Condon--Shortley 相位、(m) 顺序、实 (p,d) 顺序及归一化彼此一致。
2. 五个 (B_a) 均为 Frobenius 正交归一、实对称、迹为零。按
   
   \[
   D^d_{ab}(R)=\operatorname{tr}(B_a^{\mathsf T}RB_bR^{\mathsf T})
   \]
   
   复算两次随机旋转，群律残差为 \(7.225\times10^{-16}\)；直接点值检查 \(d_b(R^{-1}\widehat r)=\sum_a d_a(\widehat r)D^d_{ab}(R)\) 的最大误差为 \(2.776\times10^{-16}\)。因此主动作用、复合次序和 (D^p=R) 与实 (d) 表自洽。
3. 对固定非对称 \(3\times5\) 的 (p\)-(d) 块，连续执行 (R_1,R_2) 的
   
   \[
   H' = D_p(R)H D_d(R)^{\mathsf T}
   \]
   
   与一次执行 (R_2R_1) 的归一化残差为 \(2.994\times10^{-16}\)。将右侧错误写成 (D_d(R)) 而非 \(D_d(R)^{\mathsf T}\) 时，定向反例残差为 (1.305834)，远高于冻结下界 (10^{-4})。这确认工作包中的 Hamiltonian 左右作用方向可以被强反例识别。
4. 对
   
   \[
   J=\begin{pmatrix}0&1\\-1&0\end{pmatrix}
   \]
   
   独立复算得到 (JJ^*=-I)。任意固定 Hermitian \(2\times2\) 矩阵经 \(H(-k)=JH(k)^*J^\dagger\) 再作用一次能精确返回原矩阵；Zeeman 型 \(\sigma_z\) 在时间反演下变为 \(-\sigma_z\)，归一化破缺残差为 2。工作包对 θ² 的正负、反幺正共轭、磁性破缺和 Kramers 条件边界没有逻辑冲突。
5. (O(3)) 约定正确区分轨道宇称 \(p=(-1)^\ell\)、极向量与轴向量。第 18 章把 \(1\otimes1\) 的反对称三维通道识别为轴向通道，与宇称乘法和第 15/16 章的分类一致。

### M7-E-WP-B01：T-E05 将合法的 CG 输出通道相位自由误列为必失败对象

- 路径与行号：
  - `08_audits/M7_stageE_work_package.md:69`；
  - `08_audits/M7_stageE_work_package.md:100`；
  - `03_textbook/stageE_representation_conventions.md:94-107`。
- 事实：工作包要求固定 DLMF/Condon--Shortley 相位，这可以用于比对一张规范 CG 系数表；但 T-E05 的正向判据只列选择定则、正交性、维数守恒和 intertwiner，失败入口却笼统列出“符号翻转”。若把某个完整 (L) 输出通道的全部 CG 系数同时乘以 (-1)，只是对该不可约输出基作统一相位变换，选择定则、正交性和 intertwiner 全部保持。
- 独立反例：将 \(1\otimes1=0\oplus1\oplus2\) 写成标量、反对称和对称无迹的九维 Frobenius 正交基后，把整个 (L=0) 行乘以 (-1)。变换前后 `Q Q^T=I` 的误差均约为 \(6.7\times10^{-16}\)，intertwiner 残差均为 \(6.9\times10^{-16}\)。因此按 T-E05 当前列出的四项正向不变量，该“符号翻转”不会失败。
- 阻塞理由：这是强制失败矩阵中的数学假阳性要求。若实现为“任何整通道符号改变都必须破坏 intertwiner”，正确代码会被错误拒绝；若只检查 intertwiner，工作包声称的失败入口又不会被执行。
- 最小关闭条件：
  1. 明确区分“合法的整条不可约输出通道全局相位/符号自由”和“未同步改变表示、基映射或规范表的局部/相对相位错误”；
  2. 若坚持固定 DLMF/Condon--Shortley 规范，T-E05 应增加明确的相位锚点或逐项规范系数比对，并说明该检查验证的是项目规范一致性，而不是 intertwiner 本身；
  3. 把强制失败夹具改为只翻转一个非零系数、只翻转同一 (L) 通道内部分 (M) 行，或翻转输入轴但不做相应交换相位；并实际证明该夹具违反规范表或 intertwiner；
  4. 同步修订 D-E04、T-E05、C-E05 和第 18 章提纲/来源边界中的表述，避免把基自由误写成数学错误。
