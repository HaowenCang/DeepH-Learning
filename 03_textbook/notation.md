# 统一记号

本表是 M0 阶段的暂定约定。M1 阅读原始论文后，应增加“原文记号—本教材记号”对照；若原始代码使用不同轨道排序、实/复球谐或 Fourier 相位，应分别记录，不能静默替换。

阶段 B 的列基方向、实空间矩阵定义、Fourier 正反变换、有限网格归一化和轨道中心规范已经冻结在[阶段 B 统一表示与 Fourier 约定](stageB_conventions.md)；第 2、3、4、9 章应共同引用该入口。

| 符号 | 暂定含义 | 备注 |
|---|---|---|
| \(i,j,k\) | 原子索引 | 不与倒空间波矢混用 |
| \(\mu,\nu\) | 原子轨道索引 | 可与原子索引组合为 \(i\mu\) |
| \(n,m\) | 能带或本征态索引 | 具体范围按自旋与基组说明 |
| \(\mathbf R\) | 晶格平移向量 | 不默认表示原子坐标 |
| \(\mathbf r_i\) | 原子 \(i\) 的位置 | 必须说明笛卡尔或分数坐标 |
| \(\mathbf L\) | 由晶格基矢组成的晶格矩阵 | 与基变换矩阵 \(A\) 区分；列向量或行向量约定必须声明 |
| \(\mathbf k\) | 第一 Brillouin 区中的波矢 | 与原子索引 \(k\) 通过粗体区分 |
| \(|\phi_{i\mu\mathbf R}\rangle\) | 晶胞 \(\mathbf R\) 中原子 \(i\) 的局域轨道 | 归一化和实/复约定待具体基组说明 |
| \(\hat H\) | 物理哈密顿算符 | 与其矩阵表示区分 |
| \(H_{i\mu,j\nu}(\mathbf R)\) | 实空间哈密顿量矩阵元或矩阵块元素 | 原胞选取和相位约定必须明确 |
| \(H(\mathbf k)\) | 倒空间哈密顿量矩阵 | 由明确 Fourier 约定构造 |
| \(S(\mathbf R),S(\mathbf k)\) | 重叠矩阵 | 正交基中特化为单位矩阵或相应晶格形式 |
| \(c_{n\mathbf k}\) | 第 \(n\) 个 Bloch 态的基展开系数 | 非正交基下采用 \(S\)-度量归一化 |
| \(E_{n\mathbf k}\) | 本征值或能带能量 | 与总能量区分 |
| \(R\) | 三维旋转或群元素 | 与粗体晶格向量 \(\mathbf R\) 区分 |
| \(D^{(\ell)}(R)\) | 角动量 \(\ell\) 表示的旋转矩阵 | 实/复基约定必须声明 |
| \(\mathcal X\) | 完整原子结构输入 | 包含哪些元素、晶格、自旋等需逐章定义 |
| \(\widehat H\) | 模型预测的哈密顿量表示 | 不预设是否同时预测 \(S\) |

## 强制说明项

每个关键公式应说明指标范围、矩阵或张量形状、单位、基组、坐标与相位约定、主动或被动变换、实数或复数类型以及成立条件。若某一约定只影响矩阵表示而不影响物理谱，应给出相应变换或数值检验。
