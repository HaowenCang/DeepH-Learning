# 术语表（待扩充）

| 术语 | 工作定义 | 边界说明 |
|---|---|---|
| 哈密顿算符 | 决定所研究量子体系动力学或定态本征问题的算符 | DeepH 通常处理的是该算符在指定基组与电子结构设置下的矩阵表示，不是无条件的“精确哈密顿量” |
| 哈密顿量矩阵 | \(H_{\mu\nu}=\langle\phi_\mu|\hat H|\phi_\nu\rangle\) | 依赖基函数、排序、相位、规范和电子结构设置 |
| 重叠矩阵 | \(S_{\mu\nu}=\langle\phi_\mu|\phi_\nu\rangle\) | 非正交基下通常不是单位矩阵；数值病态会影响广义本征求解 |
| 不变量 | 群作用后数值不变的量或特征 | 是等变量的特殊情形，不适用于所有哈密顿量轨道块 |
| 等变量 | 输入按群作用变换时，输出按规定表示同步变换的对象 | 必须同时声明输入群作用与输出表示 |
| 局域性 | 远距离环境对局部量的影响在给定条件下衰减的性质 | 不意味着任意泛函、金属体系或长程相互作用都可用同一有限截断精确表示 |
| 复现 | 在冻结的数据、代码、配置和环境上重建报告对象及验证结果 | 只运行预训练模型或只观察损失下降不足以构成完整复现 |
