# 第 12 章 原子结构的图表示

本章把结构对象转换为可供普通消息传递网络使用的属性有向多重图。核心不是“有一张邻接矩阵”这一表面形式，而是冻结节点、边、方向、多重镜像、张量形状和预测块来源，使节点重编号后的对象能够严格配对，并使每个边输出可追溯到结构、原子对、周期镜像和轨道索引。

D-GNN-01 支持普通消息传递的节点/边接口，D-GNN-02 支持集合聚合的置换结构，D-PBC-01 提供周期晶体多重图的直接动机，DH-01 说明原子环境与局域 Hamiltonian 块之间的任务联系。周期镜像的完整枚举留到第 14 章；本章只规定边实例的数据结构。来源定位与禁止外推见 [资料包](sources.md)。

## 12.1 从结构对象到属性多重图

### 12.1.1 节点、边与结构级属性

属性图写为

\[
\mathcal G=(V,E,X,F,u).
\]

其中：

- \(V=\{0,\ldots,N-1\}\) 是规范节点索引；
- \(E\) 是有向边实例的有限序列；
- \(X\in\mathbb R^{N\times d_n}\) 是节点特征；
- \(F\in\mathbb R^{E\times d_e}\) 是边特征；
- \(u\) 保存结构级属性，例如晶格、结构 ID 和合成数据血缘。

节点索引只是一种表示，不是物理身份。结构级 `node_id` 应当稳定关联原子记录；数组行号用于当前图计算，但节点重编号时必须与边端点和输出索引同步变化。

### 12.1.2 有向边、无向关系和双向展开

阶段 D 统一约定边 \((i,j,n)\) 的 \(i\) 是接收/中心节点，\(j\) 是发送/邻居节点，\(n\in\mathbb Z^3\) 是发送节点的周期镜像。消息沿 \(j\to i\) 流动。

若底层物理邻接被视为无向关系，常见实现会为每个无向实例加入两条有向边：

\[
(i,j,n),\qquad
(j,i,-n).
\]

这两条边不是重复错误；它们服务于相反的接收节点。若构图器已经输出双向边，后续层不得再次无条件双向展开，否则聚合值会被重复计数。

### 12.1.3 多重边与自镜像边

周期图允许同一 \((i,j)\) 对应多个不同 \(n\)。因此边集合是多重图而不是简单图。完整离散边键为

\[
k_e=(\texttt{structure\_id},i,j,n_x,n_y,n_z).
\]

相同完整键重复出现属于 schema 错误；同一 \((i,j)\) 配不同 \(n\) 则是合法多重边。零位移自环 \((i,i,0)\) 按阶段 D 约定排除，而 \((i,i,n\ne0)\) 可能是合法自镜像边。

## 12.2 节点、边和图级张量

### 12.2.1 特征、索引和批维

单图的最低张量 schema 为：

| 字段 | dtype | 形状 | 语义 |
|---|---|---|---|
| `node_features` | float64 | \((N,d_n)\) | 节点输入 |
| `receiver` | int64 | \((E,)\) | 接收节点 \(i\) |
| `sender` | int64 | \((E,)\) | 发送节点 \(j\) |
| `shift` | int64 | \((E,3)\) | 周期镜像 \(n\) |
| `displacement` | float64 | \((E,3)\) | \(d_{ijn}\) |
| `distance` | float64 | \((E,)\) | \(\lVert d_{ijn}\rVert_2\) |
| `edge_features` | float64 | \((E,d_e)\) | 边输入 |
| `structure_id` | string | 标量 | 结构身份 |

必须验证 \(0\le i,j<N\)、数组第一维一致、浮点值有限、`shift` 为整数，以及 `distance` 与 `displacement` 的范数关系。隐式广播不属于 schema。

对 \(B\) 个图，拼接方案固定：

- `node_graph_id`：int64，形状 \((N_{\mathrm{tot}},)\)；
- `edge_graph_id`：int64，形状 \((E_{\mathrm{tot}},)\)；
- 两者取值范围为 \([0,B)\)；
- 图 \(g\) 的局部节点索引加前缀偏移 \(o_g=\sum_{r<g}N_r\)；
- 每条边必须满足

\[
\texttt{node\_graph\_id[receiver[e]]}
=
\texttt{edge\_graph\_id[e]}
=
\texttt{node\_graph\_id[sender[e]]}.
\]

该关系拒绝 receiver 与 sender 分属不同图的跨图边。还必须保存按图的 `node_count`、`edge_count`，二者为 int64、形状 \((B,)\)，其和分别等于 \(N_{\mathrm{tot}},E_{\mathrm{tot}}\)。

padding 方案固定最大节点数 \(N_{\max}\) 和最大边数 \(E_{\max}\)：

| 字段 | dtype | 形状 | padding 规则 |
|---|---|---|---|
| `node_features` | float64 | \((B,N_{\max},d_n)\) | 无效行全 0 |
| `node_mask` | bool | \((B,N_{\max})\) | `node_mask[g,n]` 当且仅当 \(n<N_g\) |
| `receiver`/`sender` | int64 | \((B,E_{\max})\) | 无效边为 \(-1\) |
| `shift` | int64 | \((B,E_{\max},3)\) | 无效边全 0 |
| `displacement` | float64 | \((B,E_{\max},3)\) | 无效边全 0 |
| `distance` | float64 | \((B,E_{\max})\) | 无效边全 0 |
| `edge_features` | float64 | \((B,E_{\max},d_e)\) | 无效边全 0 |
| `edge_mask` | bool | \((B,E_{\max})\) | `edge_mask[g,e]` 当且仅当 \(e<E_g\) |

有效边端点必须位于 \([0,N_g)\)，并且其节点 mask 为 true；无效边必须使用端点 \(-1\)。mask 的 true 数分别等于 `node_count[g]`、`edge_count[g]`。padding 行必须在聚合、标准化统计、归一化和损失之前被排除，不能依靠其数值恰为零。

### 12.2.2 类型、形状、单位和有限性

`receiver` 若误用浮点数，即使其数值看似整数，也应拒绝；`shift` 若被转为笛卡尔位移，会丢失镜像身份。`displacement` 与 `distance` 必须具有明确长度单位，节点/边特征的标准化统计量必须只由训练集拟合。

`NaN` 或无穷值不得在聚合后才检测。原因在于求和和最大值可能扩散或掩盖非法值，使错误难以定位到原始边实例。

### 12.2.3 padding、mask 与分段聚合

变长图批处理若使用 padding，应同时给出节点和边 mask。padding 行不得进入损失、归一化或聚合。更直接的拼接表示使用分段求和：

\[
\bar m_i=\sum_{e:\,\operatorname{receiver}(e)=i}m_e.
\]

空入边节点的 sum 按零向量定义。阶段 D 对 mean 固定

\[
\operatorname{mean}(\varnothing)=0,
\qquad
\operatorname{mean}(\mathcal M_i)
=
\frac{\sum_{m\in\mathcal M_i}m}
{\max(1,|\mathcal M_i|)},
\]

并同时输出 `has_incoming_i=(|\mathcal M_i|>0)` 的 bool mask；空入边时输出对消息的梯度为零。该约定避免除零，但零向量不能解释为观测到的真实零均值。max 聚合仍不对空集合定义，若选择 max，validator 必须拒绝任何空入边节点。sum 的零向量约定不自动推出 mean/max 的行为。

## 12.3 节点重编号与置换作用

### 12.3.1 邻接和特征的同步变换

设置换 \(p:V\to V\)，置换矩阵满足

\[
P_{p(i),i}=1.
\]

节点特征变为

\[
X'=PX,
\]

边实例变为

\[
(i,j,n)\mapsto(p(i),p(j),n).
\]

镜像向量 \(n\) 属于晶格坐标，不因节点编号置换而改变。若邻接计数矩阵定义为

\[
A_{ij}=\#\{e:\operatorname{receiver}(e)=i,\operatorname{sender}(e)=j\},
\]

则

\[
A'=PAP^\mathsf T.
\]

只置换节点数组而不更新边端点，会产生另一张图，不是合法的一致性测试。

### 12.3.2 节点等变与图级不变

节点映射 \(\Phi\) 对重编号等变，若

\[
\Phi(PX,pE)=P\Phi(X,E).
\]

图级映射 \(\Psi\) 对重编号不变，若

\[
\Psi(PX,pE)=\Psi(X,E).
\]

节点重编号等变只涉及离散索引。它不等于对三维旋转、反演或晶胞基变换等变。

### 12.3.3 边输出的重标规则

边数组本身可以任意重排。设边行置换为 \(\pi_E\)，对应矩阵为 \(Q\)。边输出 \(Y_E\in\mathbb R^{E\times d_o}\) 应满足

\[
Y'_E=QY_E
\]

并且每一行的完整离散键同步重排。比较前应按冻结键稳定排序或使用显式旧行到新行映射，不能仅比较未排序数组。

## 12.4 集合聚合

### 12.4.1 求和、均值和最大值

对接收节点 \(i\) 的入边消息多重集合 \(\mathcal M_i\)，常见聚合为

\[
\operatorname{sum}(\mathcal M_i)=\sum_{m\in\mathcal M_i}m,
\]

\[
\operatorname{mean}(\mathcal M_i)
=\frac1{|\mathcal M_i|}\sum_{m\in\mathcal M_i}m,
\]

以及逐分量最大值。三者都可对消息排列不变，但语义不同：sum 保留计数信息，mean 消除整体重复倍数，max 只保留逐分量极值。

### 12.4.2 求和聚合的次序不变性

对任意入边行置换 \(\pi\)，有限和满足

\[
\sum_{r=1}^{K}m_{\pi(r)}
=\sum_{r=1}^{K}m_r.
\]

在实数精确算术中该式严格成立。浮点加法不满足结合律，不同求和顺序可能产生舍入差异；测试应当根据规模和 dtype 冻结容差，不能把非零机器误差误判为数学不变性失败。

### 12.4.3 聚合碰撞和表达能力边界

求和并非对原始消息多重集合天然单射，例如标量集合 \(\{1,1\}\) 与 \(\{2\}\) 的和相同。D-GNN-02 的表示结论包含函数域和嵌入条件，不能简化为“直接求和可以区分所有集合”。实际模型依赖可学习消息映射、隐藏维数和后续更新，仍可能出现碰撞。

mean 还会让 \(\{1\}\) 与 \(\{1,1\}\) 完全相同，因此在邻居数本身有意义时应把计数或度数作为额外特征。max 对重复元素和非最大元素不敏感。

## 12.5 原子对边输出与轨道索引

### 12.5.1 结构—原子对—镜像—轨道对

边级目标不是无身份的向量。最低 provenance 记录包含：

\[
(\texttt{structure\_id},i,j,n,
\texttt{orbital\_i},\texttt{orbital\_j},
\texttt{block\_shape},\texttt{unit}).
\]

阶段 D 使用合成轨道索引和合成块标签，只验证追踪机制。它不选择真实元素轨道基或 DFT 标签语义。

### 12.5.2 可变块形状和掩码

若节点 \(i,j\) 分别有 \(p_i,p_j\) 个教学轨道，边块形状为

\[
(p_i,p_j).
\]

批处理可设最大展平长度 \(P_{\max}\)，要求

\[
P_{\max}\ge\max_e p_i p_j.
\]

把块按行优先展平后在右侧 padding 到 \((E,P_{\max})\)。布尔 mask 的位置而非仅数量必须满足

\[
\texttt{mask}_{ea}
\iff
0\le a<p_i p_j.
\]

因此每条边也满足必要的计数关系

\[
\sum_{a=0}^{P_{\max}-1}\texttt{mask}_{ea}=p_i p_j.
\]

padding 零不能解释为物理矩阵零，也不能进入损失。

每个有效展平位置唯一反解为

\[
\alpha=\left\lfloor\frac{a}{p_j}\right\rfloor,
\qquad
\beta=a\bmod p_j.
\]

节点分别保存有序轨道 ID 列表 `node_orbitals[i]`、`node_orbitals[j]`，长度为 \(p_i,p_j\)。为使批张量逐分量自描述，另保存 `orbital_i_index` 与 `orbital_j_index`，均为 int64、形状 \((E,P_{\max})\)：有效位置分别等于 \(\alpha,\beta\)，padding 位置为 \(-1\)。validator 必须逐位置验证 mask、反解索引和轨道列表范围；“true 数量正确但位置错误”仍应拒绝。

### 12.5.3 edge instance 身份与回溯

`edge_instance_id` 按阶段 D 契约，由规范 JSON 数组

\[
[\texttt{"stageD-edge-v1"},
\texttt{structure\_id},i,j,n_x,n_y,n_z]
\]

的 UTF-8 SHA-256 生成。ID 不包含浮点位移，从而避免容差依赖；位移和距离作为独立数值字段验证。完整键重复必须拒绝，ID 冲突也必须拒绝。

输出分量还需保存轨道对映射。例如展平顺序固定为行优先：

\[
a=\alpha p_j+\beta,
\quad
0\le\alpha<p_i,\quad
0\le\beta<p_j.
\]

若读取端采用不同展平顺序，即使向量形状相同也会产生语义错误。

## 12.6 图构造失败模式

### 12.6.1 src/dst 混淆

本项目使用 receiver \(i\)、sender \(j\)，消息沿 \(j\to i\)。若实现把 `receiver` 作为发送端，节点状态仍可能具有正确形状，但信息流方向相反。测试必须使用非对称有向图和不相同的端点特征，避免错误被对称性掩盖。

### 12.6.2 重复边静默折叠

用字典键 \((i,j)\) 保存边会覆盖不同镜像；用集合保存边会丢失多重性；对已双向展开的图再次添加反向边会把权重加倍。正确去重只针对完全相同的

\[
(\texttt{structure\_id},i,j,n_x,n_y,n_z).
\]

发现完全重复时应拒绝并定位上游构图错误，不应静默保留第一条。

### 12.6.3 单位、排序和 schema 漂移

距离单位、原子顺序、轨道顺序、展平规则或 dtype 改变都可能在数组形状不变时破坏语义。schema 应带版本号和字段关系断言；序列化内容应计算哈希。排序只用于确定性和比较，不得改变边实例集合。

## 12.7 本章边界与可验证结论

### 12.7.1 图同构不等于几何旋转等变

节点重编号只改变离散标签。旋转会改变坐标、位移向量以及轨道基表示；普通 MPNN 若直接使用笛卡尔分量，不会自动满足旋转等变。阶段 E 将单独建立群表示与轨道块协变关系。

### 12.7.2 provenance 不替代标签物理审计

完整 provenance 能回答“某个数来自哪条边、哪个轨道对”，但不能证明数值来自正确的 DFT 设置，也不能证明 Hermiticity、周期关系或下游能带正确。阶段 C 的标签语义和后续物理验证仍是独立门控。

### 12.7.3 M8/M9 授权边界

本章使用的元素类型、轨道数、边块和结构 ID 全为合成对象。M8 前不安装 DeepH、不下载正式训练数据、不生成 DFT 标签，也不选择材料、后端或实践版本。M7 与 M7-I 通过后才提交 M8 决策；M9 外部动作仍需再次授权。

## 本章可复核清单

- 能否区分节点身份、当前行号和节点置换；
- 能否说明 receiver/sender 方向及无向关系的双向展开；
- 能否保留同一原子对的多个镜像边并拒绝完整键重复；
- 能否写出节点、边、图级张量的 dtype、形状和关系；
- 能否证明求和聚合的排列不变与节点映射的重编号等变；
- 能否说明 sum/mean/max 的不同碰撞；
- 能否从边输出回溯结构、端点、镜像、轨道对和块形状；
- 能否区分离散置换一致性、几何等变性和物理标签正确性。
