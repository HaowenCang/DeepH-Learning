# 第 13 章解析与手算例题

## 例 13-1：一层标量消息

两节点有向边 \(1\to0\)，取

\[
h_0=1,\quad h_1=2,\quad
m_{01}=h_1,\quad
h_i^+=h_i+\sum_{e:r(e)=i}m_e.
\]

则 \(h_0^+=3,h_1^+=2\)。若误把 sender 当 receiver，结果变为 \(h_0^+=1,h_1^+=4\)，因此非对称单边图能检测方向错误。

## 例 13-2：同步更新与原地更新

三节点链 \(2\to1\to0\)，初值 \(h=(0,0,1)\)，每层把入边 sender 值相加。同步一层后为 \((0,1,1)\)，节点 0 尚未接收到节点 2。若按节点 1 后节点 0 原地更新，节点 0 在同一层变为 1，相当于越过两条边，破坏一层感受野。

## 例 13-3：两端点边输出感受野

边头输出 \((i,j)\) 同时读取 \(h_i^{(L)},h_j^{(L)}\)。当 \(L=1\) 时，它依赖 i 的一层前驱和 j 的一层前驱。即使某节点到 i 的距离为 2，只要到 j 的距离为 1，它仍可影响该边输出。

## 例 13-4：masked MSE 梯度

单边输出长度 4，mask=\((1,1,0,0)\)，预测与标签残差为 \((2,-1,5,7)\)。有效数 \(S=2\)，

\[
L=\frac{2^2+(-1)^2}{2}=2.5,
\]

\[
\frac{\partial L}{\partial\widehat y}
=\frac{2}{2}(2,-1,0,0)
=(2,-1,0,0).
\]

padding 残差即使很大，梯度也必须为零。

## 例 13-5：有向感受野

图只有 \(0\to1\to2\)。两层后，节点 2 可依赖节点 0；节点 0 不能依赖节点 2。把底层图无向化会错误声称双向依赖。只有显式加入反向边时，有向距离才与无向距离一致。

## 例 13-6：复杂度数量级

对隐藏宽度 \(d\)、边特征宽度 \(d_e=O(d)\)，稠密线性消息和更新每层约为

\[
O(Ed^2+Nd^2).
\]

\(L\) 层前向为 \(O(L(E+N)d^2)\)。若训练反向缓存每层节点和边激活，数组字节数量级为

\[
O(L(N+E)d).
\]

这不包含 Python 对象、索引、优化器状态和参数内存。

## 例 13-7：逐元素与逐结构损失

图 A 有 1 个有效输出，平方误差 4；图 B 有 9 个有效输出，每个平方误差 1。逐元素 MSE 为 \(13/10=1.3\)，逐结构等权 MSE 为 \((4+1)/2=2.5\)。选择何种口径会改变训练权重。

## 例 13-8：距离特征与方向特征

若边特征只有 \(r=\lVert d\rVert\)，刚体旋转后 \(r\) 不变；普通标量边头可能保持相同输入。若边特征包含 \(d_x,d_y,d_z\)，旋转后分量改变。即使只用距离，预测一个 \(p\)-轨道矩阵块仍需要非平凡表示律，不能由标量输入不变性自动得到。
