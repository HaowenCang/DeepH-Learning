# 第 8 章练习：基、赝势、采样与表示误差

本题集检验 D-C06/D-C07、T-C05—T-C08、标签表示和 M8/M9 边界。所有问题均可由第 8 章正文、例题、推导及[阶段 C 工作包](../../../../08_audits/M5_stageC_work_package.md)完成，不需要真实 DFT/DeepH 后端。

## Q8-01 分层对象链与误差归因

写出从连续 Kohn–Sham 问题到 Hamiltonian 标签制品的对象链。把 xc、赝势、cutoff、FFT 网格、\(\mathbf k\) 采样、smearing、SCF、投影和 DeepH 预测误差分别归层。判断并解释：

> DeepH 的矩阵误差趋近零，所以相对于全电子真实体系的误差也趋近零。

## Q8-02 norm-conserving 条件与边界

列出给定角动量通道、参考能量和核心半径下 norm-conserving 赝势的主要匹配条件。说明这些条件为何支持 transferability，却不证明任意环境精确。哪些身份字段必须进入标签血缘？为什么不能用这些条件替代 ultrasoft/PAW 的完整定义？

## Q8-03 从 Galerkin 投影到广义本征

从

\[
|\psi\rangle=\sum_\nu c_\nu|\phi_\nu\rangle
\]

和 Galerkin 条件推导 \(Hc=ESc\)，写出 \(H_{\mu\nu}\)、\(S_{\mu\nu}\) 和形状。证明线性无关基给出 \(S\succ0\)。说明 \(S\) 非正定或病态时应如何解释。

## Q8-04 平面波的 \(S=I\) 条件

证明固定周期胞、固定 \(\mathbf k\) 下归一化平面波彼此正交。列出从这一事实到整个离散问题 \(S=I\) 还需要的条件。解释为何“平面波基正交”不排除某些形式体系出现广义重叠算符。

再说明 cutoff、FFT 网格和 \(\mathbf k\) 网格分别控制什么，为什么三者不能互相替代。

\[
q^+=(1.12,1.03,1.008,1.002,1.0005),

和

## Q8-06 T-C06 采样与基误差

证明

\[
\frac1{2\pi}\int_0^{2\pi}e^{\cos k}\,dk=I_0(1).
\]

写出等距采样公式，复算 \(N_k=16,32,64\) 的误差。注入 \(\delta_b=10^{-2}\) 后，说明“采样已收敛”为什么不能推出总量已收敛。给出一个真实研究中保持误差轴可辨识的扫描方案。

## Q8-07 T-C07 overlap 失败样例

对工作包冻结的 \(H,S,A\)，先求原广义谱，再证明一致合同变换保持广义谱。写出逐本征对归一残差，并解释其分母各项。为什么直接计算 \(\operatorname{eigvalsh}(H')\) 是对象错误而非较粗近似？

## Q8-08 T-C08 投影与等谱

设 \(B^\dagger B=I\)。证明

\[
H_r=B(B^\dagger HB)B^\dagger=P_BHP_B
\]

和 \(P_BH_rP_B=H_r\)。解释丢失范数的语义和不能支持的外推。

再证明 unitary 相似变换保持谱，并说明为什么固定坐标中的矩阵差仍可大于 0。若 \(B^\dagger B\ne I\)，应如何修改投影、本征问题、完整空间回投算符与丢失范数？给出一个因错误照搬 \(BH_BB^\dagger\) 而依赖基缩放的反例。

## Q8-09 smearing、能量与标签 schema

区分数值 smearing 和物理有限温度。列出至少三种可能的能量报告口径，并说明比较时为何必须一致。

依据 stageC-label-v1 构造一条合成标签摘要，至少覆盖后端/制品哈希、理论与赝势、基/采样/占据、收敛、\(H/S\) 表示、Fourier/规范、投影窗口/维数/损失、验证环境。所有真实选择使用允许的未决值。

## Q8-10 综合诊断与授权边界

某结果满足：

- SCF 残差 \(<10^{-10}\)；
- 32/64 \(\mathbf k\) 网格结果差 \(<10^{-8}\)；
- 投影后能带窗口内最大误差 \(<10^{-3}\)；
- 标签没有赝势哈希、轨道顺序和相位规范；
- 只比较了一个 cutoff；
- overlap 被省略。

逐项判断哪些结论可以成立、哪些证据不足或对象错误，并设计最小补充验证。最后说明 M8 前仍禁止哪些动作，以及 M8 冻结后开始 M9 正式安装/下载/复现前还需要什么。
