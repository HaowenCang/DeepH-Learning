# 阶段 C 综合问题参考解答

## C-C01

固定核时，\(R\) 被当作参数。电子 Hamiltonian 为

\[
\hat H_e(R)=\hat T_e+\hat V_{ne}(R)+\hat V_{ee},
\]

而 \(V_{nn}(R)\) 是给定几何上的常数，可在电子能量后加回。被删除的是作用于核坐标的 \(\hat T_n\)；这不是声称核的物理动能恒为零。把 \(\Psi=\sum_a\chi_a\Phi_a\) 代回总方程时，\(\hat T_n\) 作用于乘积，产生

\[
-\sum_I\frac{1}{2M_I}
\left[
2\langle\Phi_a|\nabla_I\Phi_b\rangle\cdot\nabla_I
+\langle\Phi_a|\nabla_I^2\Phi_b\rangle
\right],
\]

即一阶和二阶导数耦合。只有选择单一隔离绝热面、控制非绝热跃迁，并在局部规范与 Born–Huang 修正上作额外近似，才得到最简裸核动能加势能面方程；简并与全局 Berry 相位不能由局部相位选择普遍删除。

对占据轨道 \(\{\phi_i\}_{i=1}^{N}\)，单 determinant 的 1RDM 为

\[
\gamma=\sum_{i=1}^{N}|\phi_i\rangle\langle\phi_i|.
\]

若 \(|\phi'_i\rangle=\sum_j|\phi_j\rangle U_{ji}\) 且 \(U^\dagger U=I\)，则

\[
\gamma'=\sum_{ijk}|\phi_j\rangle U_{ji}U^*_{ki}\langle\phi_k|=\gamma.
\]

密度是 \(n(r)=\gamma(r,r)\)，同样不变；determinant 只乘 \(\det U\) 的整体相位。此时 \(\gamma^2=\gamma\)。一般相关态的自然占据数可位于 0 与 1 之间，故 1RDM 通常不幂等；因此“1RDM 幂等”等价于这一类单 determinant 结构，而不是任意费米多体态定理。

## C-C02

HK 唯一性针对固定相互作用和粒子数的基态问题；外势最多确定到加法常数。标准反证需要处理两个势是否共享基态；简并情形不能把非简并证明逐字套用。Levy 纯态 constrained search 可写为

\[
F_{\mathrm{LL}}^{\mathrm{pure}}[n]
=\inf_{\Psi\mapsto n}\langle\Psi|\hat T+\hat W|\Psi\rangle,
\]

其域是由反对称纯态产生的密度。系综搜索扩大状态类；Lieb 泛函可由能量的 Legendre–Fenchel 对偶得到，并在适当函数空间与拓扑下对应纯态搜索泛函的凸、下半连续闭包。把 `infimum` 无条件改写为任意密度上由某个纯态取得的 `minimum` 是错误的。

四种可表示性分别询问：密度是否由某个相互作用 \(N\) 电子态产生；是否由某个相互作用外势的基态产生；是否由某个非相互作用 \(N\) 电子态/系综产生；是否由某个局域非相互作用势的基态产生。后一项比前一项更强。

题给句子不成立。修正为：在定理适用的固定相互作用与基态条件下，基态密度确定外势至多差常数；这不说明任意非负归一化函数都是 \(v\)-representable，也不保证搜索下确界对任意扩展域都由单个纯态取得。

## C-C03

对正交轨道引入 Hermitian 乘子矩阵 \(\Lambda\)：

\[
\delta\left(E-\sum_{ij}\Lambda_{ij}
(\langle\phi_i|\phi_j\rangle-\delta_{ij})\right)=0.
\]

利用

\[
\frac{\delta E_H}{\delta n}=v_H,
\qquad
\frac{\delta E_{xc}}{\delta n}=v_{xc},
\]

并在占据空间对角化 \(\Lambda\)，得到

\[
\left[-\frac12\nabla^2+v_{\mathrm{ext}}+v_H+v_{xc}\right]\phi_i
=\varepsilon_i\phi_i.
\]

本征值和满足

\[
\sum_i f_i\varepsilon_i
=T_s+\int n(v_{\mathrm{ext}}+v_H+v_{xc}),
\]

因此总能量可写为

\[
E=\sum_i f_i\varepsilon_i-E_H[n]-\int n v_{xc}+E_{xc}[n],
\]

其中 \(\int nv_H=2E_H\)，故需减去一次 Hartree 双计数，并修正 \(v_{xc}\) 与 \(E_{xc}\) 的差。KS 映射的精确形式只把未知多体效应集中到 \(E_{xc}\)；实际计算仍需近似。除受附加定理支持的特殊量外，KS 辅助本征值不能普遍解释为全部加/去电子或中性激发能。

## C-C04

固定点为

\[
x_*=(I-J)^{-1}b
=(0.375,-0.4,1/14)^T.
\]

误差满足

\[
e_{m+1}=M_\alpha e_m,
\qquad
M_\alpha=(1-\alpha)I+\alpha J.
\]

当 \(\alpha=0.8\) 时，对角元为 \((0.36,0.60,-0.12)\)，故 \(\rho(M_\alpha)=0.6<1\)。当 \(\alpha=2\) 时，对角元为 \((-0.6,0,-1.8)\)，故谱半径为 1.8，第三模增长。失败协议应记录 \(x_0\)，再恰执行 12 次更新得到 \(x_{12}\)，从而有 13 个残差值而不是暗中执行第 13 次更新。冻结实现得到末/初残差比约 309.176，大于 10。

若 \(x_0=x_*\)，第 0 步已收敛，应返回 `iterations=0`、零残差和 `estimated_rate=null`。此时不存在用于估计渐近比率的非零误差对，不能除以零或伪造速率。

## C-C05

映射按构造保持分量和为 1，但归一化只说明迭代仍在粒子数超平面上，不说明是固定点。正例 \(\alpha=0.25\) 在冻结实现中 16 步达到密度残差约 \(8.61\times10^{-10}\)，归一化误差为 0，所有分量非负；能量变化也低于 \(10^{-9}\)。因此每步仍须验证 shape `(2,)`、有限性、粒子数、正性，并在终点同时验证 \(R_m\) 与相对能量变化。

\(\alpha=1\) 产生两周期，20 步末残差约 1.353，虽归一化仍成立也必须标记 `oscillation_or_divergence`。把报告能量乘 \(10^{-12}\) 可使某步能量变化低于 \(10^{-10}\) 而密度残差大于 1，证明 energy-only 会误通过。达到 `max_iter=20` 只表示预算耗尽，应返回 `converged=false` 和 `termination_reason=max_iterations`。

最小规范记录应包括输入参数、seed、初值、每步输入/输出密度、残差、能量及变化、约束指标、迭代数、收敛布尔量和终止原因，并保存容差和版本。墙钟时间受调度与机器负载影响，不属于数学轨迹；把它放入规范 JSON 会使相同输入的哈希不确定。

## C-C06

正序列最后三个参考误差为

\[
(0.008,0.002,0.0005),
\]

最后两个相邻差为 \(0.006\) 和 \(0.0015\)。它们分别满足“小于 \(10^{-2}\)”“最后一级小于 \(10^{-3}\)”和“最后两差小于 \(10^{-2}\)”。负序列最后三个参考误差为 \((0.002,0.0015,0.008)\)，最后两差为 \(0.0005\) 和 \(0.0065\)；尽管 32/64 一对形成假平台，128 级参考误差仍为 0.008，超过失败判据 \(5\times10^{-3}\)。因此必须检查多层级和参考误差。

对周期解析函数，等权网格积分的采样误差在 16、32、64 点已降至冻结阈值以下；但若结果再加固定基偏置 0.01，则 32/64 之差仍几乎为零，而相对精确参考的总误差约 0.01。题给结论不成立：相邻采样差只约束采样轴，不能消除独立的基、理论、SCF 或投影偏差。

## C-C07

由于两矩阵对角，广义特征值为 \(H_{ii}/S_{ii}\)：

\[
E=(-1.2,-0.1,0.8,2.0).
\]

若 \(c'=A^{-1}c\)，则

\[
H'c'=A^\dagger Hc=E A^\dagger Sc=ES'c',
\]

且 \(\det(H'-ES')=|\det A|^2\det(H-ES)\)。可使用

\[
r=\frac{\|H'c-E S'c\|_2}
{(\|H'\|_2+|E|\|S'\|_2)\|c\|_2}
\]

作为后向残差。普通 `eigvalsh(H')` 删除了 \(S'\)，求解的是不同矩阵束；冻结反例的最大谱差约 0.967，大于 0.1。

正交子空间下

\[
H_p=B^\dagger HB,
\qquad
H_r=BH_pB^\dagger,
\]

并满足 \(B^\dagger H_rB=H_p\) 与 \(H_r=B(B^\dagger H_rB)B^\dagger\)。在非正交目标基中还需 Gram 矩阵及稳定求解，不能照抄 \(B^\dagger B=I\)。默认 T-C08 的相对丢失范数约 0.960，明确显示降维损失。

T-C08 的等谱反例使用题面另行定义的 \(d=12\)、seed 20260805 随机正交模型 \(H^{(12)}\)，不是题首四维对角 \(H\)。对固定标准基 0、1 维旋转 0.37 rad，独立计算得到

\[
\max_i|\lambda_i(H^{(12)})-\lambda_i(H_2^{(12)})|
\approx4.44\times10^{-15},
\]

\[
\frac{\|H^{(12)}-H_2^{(12)}\|_F}{\|H^{(12)}\|_F}
\approx0.23306076>0.15.
\]

若把相同旋转直接作用于题首四维对角 \(H\)，相对矩阵差仅约 0.10421583，不满足 T-C08 的 \(>0.15\) 冻结失败阈值；因此两个模型的数值不得互换。若监督目标冻结了轨道顺序、相位和坐标，等谱矩阵仍是不同坐标标签；只有同时记录并应用表示映射，才能解释为同一抽象算符。

## C-C08

七个技术层依次为：路径层排除缺字段；结构层联合检查类型、shape、有限性和数组关系；身份层验证制品内容哈希；授权层阻止提前选择 M8 实践对象；数值层验证 Hermiticity、\(S\succ0\)、残差、投影和截断指标；语义层验证单位、轨道顺序、bra/ket、晶格位移方向、Fourier、规范和 overlap 处理；前向层分别验证矩阵、谱、目标子空间及适用物理量。第八步是独立审计，主实现自报 `pass` 不能替代。任何一层通过都不能替代其后层。

题给变异分别应定位到 `convergence.max_iterations` 的整数类型、`structure.lattice` 的数值元素、`sampling.k_mesh` 的三维 shape、`representation.output_object` 的数组类型、具体 SHA 路径的内容重算，以及 `structure.species`、`basis.type`、`sampling.kind`、`projection.method` 的 M8/合成白名单。`"0"*64` 虽格式合法但与合成内容不符，仍必须失败。

67 个删除测试只证明每个路径被访问且缺失时失败；它不能证明已有字段的值类型、形状、数组关系、内容身份或授权状态正确。T-C09 因而另执行 47 个对抗变异，分类为 type 9、shape 11、hash 8、M8 choice 19，并在 JSON 中分别报告期望数、捕获数、路径和错误见证。这 47 项直接覆盖结构、身份和授权中的冻结负例，但不等于穷尽语义层或前向层；后两层仍需专门的表示一致性与物理量验证。

## C-C09

令 \(A^{(R_c)}_{ij}=A_{ij}\mathbf 1(R_{ij}\le R_c)\)。三指标为

\[
s(R_c)=\frac{\#\{(i,j):A^{(R_c)}_{ij}\ne0\}}{N^2},
\]

\[
e_F(R_c)=\frac{\|A-A^{(R_c)}\|_F}{\|A\|_F},
\qquad
e_x(R_c)=\frac{\|Ax-A^{(R_c)}x\|_2}{\|Ax\|_2}.
\]

默认指数族在 \(R_c=(2,4,8,16)\) 的 \(e_F\) 约为 \((0.2639,0.09547,0.01247,0.000211)\)，作用量误差约为 \((0.2687,0.09619,0.01227,0.000194)\)。每个 JSON 值都从原矩阵与截断矩阵复算，可发现记录器或索引故障；单报非零比例不能说明作用量误差。

指数族满足 \(\log A=-R/2\)，理论斜率为 \(-0.5\)。代数族满足 \(\log A=-\log(1+R)\)，其局部斜率随距离变化，不是单一常数。把 1—8 的指数拟合外推到 16—31，冻结相对残差约 0.843，大于 0.8，故必须拒绝。

电子近视性讨论局部势扰动对远处局部观测的影响；1RDM 衰减讨论核 \(\gamma(r,r')\) 随分离的行为；固定基下 \(H/S\) 块稀疏还依赖轨道局域性、表示和阈值。三者条件相关但不等价，任意非局域基变换都可能改变矩阵稀疏模式而不改变抽象物理态。

## C-C10

端到端审计表的最低内容如下：

| 箭头 | 误差来源 | 证据字段 | 强制失败示例 |
|---|---|---|---|
| 结构 \(\to\) 固定核对象 | 单位、边界、物种/位置错配 | structure 全组、内容哈希 | species 与 positions 长度不同 |
| 固定核 \(\to\) 理论层级 | BO/相对论/自旋条件不明 | theory、spin | M8 前把 SOC 静默设为 false |
| 理论 \(\to\) 离散基/采样 | XC、赝势、基、网格混用 | theory、basis、sampling | 只收敛 \(k\) 点却声明基已收敛 |
| 离散 \(\to\) SCF 固定点 | 混合振荡、阈值误判 | convergence 阈值与 achieved metrics | `max_iter` 当作收敛 |
| SCF \(\to\) 投影/矩阵 | 能窗丢失、非正交回投错误 | projection、representation | 忽略 \(S\) 或等谱即同矩阵 |
| 矩阵 \(\to\) 标签记录 | 单位、轨道顺序、Fourier/规范错配 | representation、artifacts | 正反 Fourier 同号 |
| 标签 \(\to\) 训练/推理 | 数据划分、尺度和模型误差 | 留待 M8/M9 冻结的训练记录 | 训练 MAE 代替 OOD/前向验证 |
| 预测 \(\to\) 物理量 | Hermiticity、广义谱、截断误差 | matrix/band validation | 小矩阵 MAE却破坏谱或对称性 |

阶段 C 已验证多体—密度—KS—SCF 的概念与推导边界，演示基/采样/投影误差分层，冻结标签 schema，并用合成对象验证 T-C01—T-C10 及失败检测。它没有选择计算资源、DFT/数据后端、DeepH 软件对象、首个材料体系、时间/训练预算或高级物理范围，也没有生成正式标签。

第一道门槛是 M7-I 通过后进入 M8，集中提交并冻结上述实践决策。第二道门槛是在 M8 已冻结后、开始 M9 的正式安装、数据下载、DFT 计算或复现实验前再次取得明确执行授权。二者不能合并，材料建设和合成测试也不能替代外部动作授权。
