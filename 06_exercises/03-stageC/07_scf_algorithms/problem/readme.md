# 第 7 章练习：SCF 算法

本题集检验固定点对象、混合稳定性、约束、停止条件、失败状态、成本和标签语义。Q7-01—Q7-10 均可依据第 7 章正文、例题和 D-C05 完成；Q7-09 还使用[阶段 C 工作包第 7 节](../../../../08_audits/M5_stageC_work_package.md)，Q7-10 还使用[决策记录 D-010/D-011](../../../../decisions.md)。不需要安装或运行真实 DFT/DeepH 后端。

## Q7-01 自洽对象链与成本

写出从输入密度到输出密度的一次 Kohn–Sham 映射对象链，并定义一次 SCF 迭代和一次完整 SCF。说明为什么以下三个比较都需要统一输出任务和精度口径：

- 两种 SCF 算法的迭代次数；
- 一次完整 SCF 与一次 DeepH 推理；
- Hamiltonian 预测与能带后处理。

## Q7-02 固定点、残差与约束

定义 \(F[n]\)、\(R[n]\) 和线性混合 \(G_\alpha[n]\)。证明当 \(\alpha\ne0\) 时 \(F\) 与 \(G_\alpha\) 的固定点相同，并解释 \(\alpha=0\) 为什么是例外。

若 \(n_m\) 与 \(F[n_m]\) 均非负且积分为 \(N_e\)，证明 \(0\le\alpha\le1\) 时混合密度保持这些约束。说明该证明为什么不能作为收敛证明。

## Q7-03 Jacobian 线性化

设 \(F\) 在固定点 \(n_*\) 附近 Fréchet 可微。从

\[
n_{m+1}=n_m+\alpha(F[n_m]-n_m)
\]

推导误差迭代矩阵

\[
M_\alpha=(1-\alpha)I+\alpha J_*.
\]

列出用 \(\rho(M_\alpha)<1\) 推出收敛所需的局部条件，并说明模等于 1 的情形为什么不能由一阶线性化定论。

## Q7-04 冻结三维线性模型

对

\[
F(x)=Jx+b,\quad
J=\operatorname{diag}(0.2,0.5,-0.4),\quad
b=(0.3,-0.2,0.1)^T,
\]

完成以下计算：

1. 求 \(x_*=(I-J)^{-1}b\)；
2. 对 \(\alpha=0.8\) 求 \(M_\alpha\) 和谱半径，并预测渐近收敛率及是否含振荡模；
3. 对 \(\alpha=2\) 求谱半径并判断稳定性；
4. 说明 \(x_0=x_*\) 时收敛率估计应返回什么及原因。

## Q7-05 标量稳定区

若 \(J_*\) 的一个实特征值为 \(\lambda\)，推导

\[
\mu_\alpha=1-\alpha+\alpha\lambda
\]

及正 \(\alpha\) 下的稳定区。分别讨论 \(\lambda<1\)、\(\lambda=1\) 和 \(\lambda>1\)。说明为什么复特征值不能直接使用同一个实区间公式。

## Q7-06 非正规矩阵与局部/全局边界

考虑

\[
M=
\begin{pmatrix}
0.5&20\\
0&0.5
\end{pmatrix},
\qquad
e_0=(0,1)^T.
\]

计算谱半径和第一步误差范数放大倍数。该矩阵最终是否收敛？这个例子反驳了下列哪一个命题，未反驳哪一个命题？

1. \(\rho(M)<1\) 保证每一步误差范数单调下降；
2. 对固定有限维线性迭代，\(\rho(M)<1\) 保证 \(M^m\to0\)。

再列出两个使真实非线性 SCF 不能从固定点 Jacobian 得到全局保证的原因。

## Q7-07 非线性两分量密度

对

\[
F_i(n)=
\frac{\exp[-(v_i+4n_i)]}
{\sum_j\exp[-(v_j+4n_j)]},
\qquad
v=(-0.1,0.1)^T,
\qquad
n_0=(0.9,0.1)^T,
\]

写出数值稳定的 softmax 实现和残差 \(R_m\)。比较 \(\alpha=0.25\) 与 \(\alpha=1\) 的冻结结果，并说明后者保持归一化为什么仍应标记为失败。答案应给出迭代数、最终残差和终止原因。

列出一条完整终止记录至少需要的字段，并说明达到最大迭代数但残差未通过时的唯一正确状态。

## Q7-09 T-C01—T-C04 可验证规范

## Q7-10 预条件、标签与 M8/M9 边界

\[
n_{m+1}=n_m+\alpha P(F[n_m]-n_m)
\]

在 \(n_*\) 附近的一阶矩阵。说明粒子数保持对 \(P\) 有什么要求，并列出历史混合必须登记的四类语义。

随后构造一条 SCF 标签血缘摘要，至少包括残差定义、阈值与达到值、能量口径、本征求解阈值、最大/实际迭代数、终止原因和约束误差。最后回答：M8 前为何不能把本题的 \(P\)、\(\alpha\) 或两分量模型变成真实后端默认选择；M8 冻结后、M9 正式安装或数据下载前还需要什么。
