# 01.03 数值编程题

允许使用 NumPy/SciPy。每题必须提交固定随机种子或显式矩阵、运行命令、自动测试、至少一个故意失败样例和结果解释；仅给出成功输出不构成通过。

### P1 两轨道非正交模型

实现

\[
H=\begin{pmatrix}\varepsilon_1&t\\t^*&\varepsilon_2\end{pmatrix},\qquad
S=\begin{pmatrix}1&s\\s^*&1\end{pmatrix},\quad |s|<1.
\]

比较闭式根与数值广义本征值；执行非幺正可逆基变换并验证谱不变。失败样例应至少覆盖 \(|s|\ge1\) 或只变换 \(H\)。

### P2 同范数不同方向扰动

构造两个 Frobenius 范数相同的厄米 \(\delta H\)，使一个投影到目标低能本征态，另一个投影到与其 \(S\)-正交的高能态。比较全谱 MAE、目标本征值位移和低能窗最大误差，并说明结果能推出什么、不能推出什么。

### P3 周期矩阵 Fourier 正反变换

在一维有限平移集合上构造 \(H(R)\)，满足 \(H(R)^\dagger=H(-R)\)。实现离散正反 Fourier 变换并测试：

- 每个采样 \(k\) 点上 \(H(k)=H(k)^\dagger\)；
- 反变换重建误差小于预定容差；
- 删除 \(H(-R)=H(R)^\dagger\) 配对后，Hermiticity 测试必须失败；
- 改变正反变换相位约定但未同步修改时，重建或定位测试必须失败。

## 建议门槛

双精度、条件适中的教学样例中，广义本征残差与谱不变误差应接近机器精度；容差应根据矩阵尺度和条件数声明，不应机械推广到病态或大规模问题。
