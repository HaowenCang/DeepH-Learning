# 01.05 端到端对象图综合材料题

## 自学任务

分别绘制 DeepH 的训练链与新结构推理链，并对每一条箭头填写审计表。建议先不查看参考解答；可选保存三个学习过程文件：

- `first_attempt.md`：第一次闭卷作答，不覆盖；
- `revised_attempt.md`：核对后修正版；
- `revision_log.md`：逐项写明原判断、修正、理由和证据位置。

上述学习过程文件不是 M3 阻塞证据。材料门控检查的是本题、空白模板、完整参考解答、关键错误量规和验证入口是否齐全。

每个节点必须标注对象类型：算符、给定基中的矩阵、监督标签、模型预测、辅助输入、本征量或进一步物理量。每条箭头至少包含：输入、输出、固定约定、成立假设、可能误差和可执行验证。

训练链必须包含结构与固定 DFT 设置、电子结构数据/辅助对象、标签和图预处理。推理链必须包含新结构、周期原子图、预测矩阵、必要的 \(S\)、统一坐标下的块组装、Fourier 变换、广义本征求解、占据和性质后处理。

还应完成以下定位：

- 圈出原始 DeepH 在新结构上替代的 SCF 标签生成环节；
- 列出未被替代的物理近似、训练数据成本和推理后步骤；
- 在链上定位原始 DeepH、HPRO、DeepH-dock、DeePTB 和 DeepH-R；若不属于同一箭头，应说明其改变的是标签获得路径、软件接口、学习目标或问题定义。

## 判定规则

采用关键错误一票否决。出现下列任一项即不通过：

- 混淆算符、参考矩阵、预测矩阵、本征值和总能量；
- 把 \(S\) 统一写成所有版本的网络监督目标或网络输出；
- 把“跳过 SCF”写成跳过组装、Fourier、广义本征、占据或全部后处理；
- 训练链或推理链缺少任一规定节点；
- 把 HPRO 或 DeepH-dock 写成预测 GNN；
- 强行把不同学习目标视为同一箭头而不说明语义差异；
- 参考解答缺少完整对象图、逐箭头字段或错误修正机制。

对材料本身，零关键错误且题目、模板、参考解答、节点和箭头字段完整时才判定通过。学习者是否实际提交作答不影响材料门控。
