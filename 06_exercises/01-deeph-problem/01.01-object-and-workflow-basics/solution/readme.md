# 01.01 对象与工作流基础题参考解答

## B1 对象区分

\(\hat H_{\mathrm{KS}}\) 是在给定电子结构理论设置下定义的算符。选定有限基 \(\{\phi_\mu\}\) 后，参考矩阵元素为

\[
H_{\mu\nu}=\langle\phi_\mu|\hat H_{\mathrm{KS}}|\phi_\nu\rangle .
\]

因此，\(H\) 是算符在特定基、轨道排序、相位、单位和电子结构设置下的表示。\(\widehat H\) 是模型对该标签对象的估计，不是新的物理算符定义。\(E_n\) 是由 \((H,S)\) 的本征问题得到的本征量；在周期体系中还带有 \(\mathbf k\) 指标。总能量通常还包含占据、双计数修正及所用电子结构理论规定的其他项，不能等同于某个 \(E_n\) 或本征值简单求和。

基变换会改变 \(H\)、\(S\)、\(\widehat H\) 的矩阵元素和本征矢坐标；在变换一致且问题定义不变时，广义本征值不应任意改变。核验应同时检查基/索引元数据、矩阵关系和下游谱，而不能只比较文件形状。

## B2 非正交基

局域轨道一般满足 \(S_{\mu\nu}=\langle\phi_\mu|\phi_\nu\rangle\neq\delta_{\mu\nu}\)。把 \(|\psi\rangle=\sum_\nu c_\nu|\phi_\nu\rangle\) 投影到每个基函数便得到 \(Hc=ESc\)。基础厄米定问题要求 \(H=H^\dagger\)、\(S=S^\dagger\succ0\)，本征矢可取 \(c_m^\dagger S c_n=\delta_{mn}\)。只有当所用基已正交归一，或已通过声明的可逆正交化变换把问题化到正交基中时，才可在变换后的表示写 \(S=I\)；不能在原非正交基中直接丢弃 \(S\)。核验包括 \(S\) 的最小本征值、条件数和 \(S\)-正交残差。

## B3 推理后的计算

可归并为四类：

1. 获得与目标表示一致的 \(S\) 及其他辅助算符；
2. 把局域块旋回统一坐标，按原子、轨道和晶格平移索引组装，并执行实—倒空间 Fourier 变换；
3. 求解 \(H(\mathbf k)c=E S(\mathbf k)c\)，处理简并、能带排序和数值条件；
4. 施加占据并计算态密度、总能量或响应等进一步物理量。

原始 DeepH 主要替代新结构上为生成目标 Hamiltonian 标签而进行的昂贵 SCF 路径，不自动消除电子结构理论近似、训练数据生成成本或上述下游步骤。可执行核验是从新结构开始逐节点追踪文件/张量，并对组装、Hermiticity、广义本征残差和目标物理量分别设门槛。

## B4 标签语义

- 更换交换-相关泛函会改变有效 Kohn–Sham 势和算符，属于理论层级或物理近似改变；标签矩阵和谱通常随之改变。
- 更换赝势会改变离子—电子作用、价电子空间及可能的投影定义，也会改变标签语义。
- 更换基组会改变有限维表示空间和矩阵元素；即使目标算符概念相同，两个矩阵也未必具有相同维数或逐元素可比性。
- 仅改变轨道顺序属于索引变换。若 \(P\) 为置换矩阵，应同时变换 \(H'=P^\dagger HP\) 与 \(S'=P^\dagger SP\)。相位翻转或轨道幺正混合也属于表示变换，但不是逐元素不变。

核验时应冻结“理论层级—赝势—基组—轨道顺序/相位—单位”，并在可判定为纯表示变换时检查一致变换后的谱。

## B5 工作流角色

原始 DeepH 学习“结构或周期图到特定局域 AO Hamiltonian 块”的映射。HPRO 处理标签表示桥接，把平面波 DFT 的波函数或实空间信息投影/重建为选定 AO 表示中的 \(H/S\)；它不是预测新结构 Hamiltonian 的 GNN。DeepH-dock 面向 DFT 接口、标准化数据和矩阵后处理，可承担 overlap、对角化、波函数及格式转换等环节；它也不是学习网络本身。

实践前应分别冻结 DeepH 模型/提交及配置、HPRO 支持的输入后端与投影设置、DeepH-dock 发布版本与转换/后处理字段，并用一个最小样例核验矩阵维数、单位、轨道顺序、重构谱和接口可用性。现有章节只支持这些角色边界，不支持断言任意后端和任意格式均已兼容。
