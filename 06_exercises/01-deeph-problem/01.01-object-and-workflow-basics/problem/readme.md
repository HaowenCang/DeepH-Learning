# 01.01 对象与工作流基础题

## 作答要求

每题应先给出直接结论，再写出成立条件、至少一个易混淆对象和一个可执行核验。不得把特定论文或软件版本的接口外推为所有 DeepH 方法共有属性。

### B1 对象区分

区分 Kohn–Sham 算符 \(\hat H_{\mathrm{KS}}\)、给定基中的参考矩阵 \(H\)、模型预测矩阵 \(\widehat H\)、本征值 \(E_n\) 和体系总能量。说明其中哪些对象依赖基表示，哪些对象不能由单个本征值替代。

### B2 非正交基

说明局域轨道基为何需要重叠矩阵 \(S\)，广义本征问题为何写成 \(Hc=ESc\)，以及在什么条件下可以令 \(S=I\)。

### B3 推理后的计算

列出 DeepH 预测 Hamiltonian 后仍可能需要的四类计算或辅助对象，并解释“跳过新结构上的 SCF 标签生成”为什么不等于“跳过全部电子结构后处理”。

### B4 标签语义

分别说明更换交换-相关泛函、赝势、基组和轨道顺序如何影响监督标签。区分物理内容改变、表示改变和纯索引变换。

### B5 工作流角色

比较原始 DeepH、HPRO 与 DeepH-dock 的主要工作流角色。指出三者分别改变或承担哪一类箭头，并列出实践前需要按固定版本核验的内容。

## 最低通过标准

- 五题均区分算符、矩阵、预测和本征量；
- B2 明确 \(S\) 的正定性条件；
- B3 不把 overlap、组装、Fourier 变换和广义本征求解统一写成已被省略；
- B5 不把 HPRO 或 DeepH-dock 写成 Hamiltonian 预测 GNN。
