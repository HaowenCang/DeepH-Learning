# 01.04 研究讨论题

讨论题应明确区分已知事实、由定义直接推出的结论、待验证假设和实验建议。不得在没有统一数据、标签与预算的条件下给出方法优劣排序。

### R1 改变学习对象

若把学习目标由特定 AO 基中的 Hamiltonian 矩阵改为实空间 Kohn–Sham 势，哪些 AO 基依赖从监督目标中消失？哪些电子结构理论、空间离散、规范、投影和下游求解依赖仍然存在？设计至少三项验证以区分势误差、投影误差和谱误差。

### R2 公平比较不同 Hamiltonian 方法

设计一个比较 DeepH-E3、DeePTB 和 HamGNN 的基准。要求列出：数据与结构划分、电子结构标签设置、基与索引约定、训练预算、矩阵与下游指标、对称性测试、统计不确定性和计算成本。若三种方法的监督目标不能完全统一，应如何组织结果并限定结论？

## 最低通过标准

R1 不把“基组无关学习目标”写成“整个计算链无表示误差”；R2 不用未对齐的矩阵 MAE或单一论文数字直接排序方法。
