# 01.04 研究讨论题参考解答

## R1 改变学习对象

把监督目标设为实空间 Kohn–Sham 势后，标签不再直接绑定某一组 AO 轨道的维数、排序、相位及轨道间幺正混合；由同一势在不同基中计算矩阵时，AO 表示依赖被推迟到势到矩阵的积分/投影步骤。这一结论只涉及学习对象，不表示所有基依赖和数值误差消失。

仍然存在的依赖包括：交换-相关泛函、赝势和自旋等电子结构理论设置；势的零点或其他规范约定；实空间网格、边界与插值；从势构造矩阵时的 AO 基、积分精度和截断；非局域赝势等不能由单一局域标量势完整表述的部分；\(S\)、Fourier 组装、广义本征求解、占据和性质后处理。具体 DeepH-R 实现能覆盖哪些势分量和软件接口，应以固定版本代码与数据说明核验，现有证据不足以把方法概念直接外推为完整公开复现能力。

可分层验证：

1. 在同一网格和规范下比较预测势与参考势，并报告空间分区误差；
2. 用同一参考 AO 基和同一积分器分别从预测势、参考势构造矩阵，分离势误差传播与积分误差；
3. 对两组矩阵执行相同广义本征求解，比较全谱、目标能窗和简并子空间；
4. 改变网格与 AO 基进行收敛测试，检查结论是否受离散选择主导。

## R2 公平比较不同 Hamiltonian 方法

一个可审计基准应先冻结共同部分：结构集合与去重规则；按材料/构型组而非相邻帧随机划分；同一 DFT 理论层级、赝势、自旋、\(k\) 点和收敛阈值；若比较 AO 矩阵，则固定基组、轨道顺序、相位/规范、单位和截断；相同训练/验证/测试结构及预处理信息边界；等量或分别报告的参数量、训练步数、优化搜索预算、硬件和墙钟时间；至少多个随机种子。

指标应分层报告：矩阵块误差及其按轨道/距离分解；Hermiticity、周期平移与随机旋转协变残差；全谱、目标能窗、带隙/带宽和简并子空间误差；分布内/外结果；训练、推理与后处理成本。所有方法应由同一外部脚本执行下游组装和求解，或证明各自后处理等价。

若 DeePTB 的监督目标是环境依赖 tight-binding 参数或能带，而其他方法逐元素学习固定 AO Kohn–Sham 矩阵，则逐元素矩阵 MAE没有共同定义域。此时应把结果分为两层：在各自原生目标内报告方法内指标；在共同结构、共同能窗和共同后处理口径下比较下游谱及成本。结论只能限定为“在该数据、预算、目标语义和指标下的结果”，不能据此判定架构本身的普遍优劣。
