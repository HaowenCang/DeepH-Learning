# 第 15 章练习：问题

## Q15-01 概念分类

分别定义主动旋转、被动坐标变换、不变量和等变映射。说明“不变”如何作为等变的特例出现。

## Q15-02 主动/被动数值题

对

\[
R_z(\pi/2)=
\begin{pmatrix}
0&-1&0\\
1&0&0\\
0&0&1
\end{pmatrix},
\qquad
v=(1,2,3)^{\mathsf T},
\]

分别计算主动旋转后的向量和被动换基后的坐标。解释二者为何不同。

## Q15-03 行晶格桥接

已知分数坐标按行存储且 \(r=fA\)。从列向量主动旋转 \(r'_{\mathrm{col}}=Rr_{\mathrm{col}}\) 推导行晶格的变换。说明 \(RA\) 为什么通常错误。

## Q15-04 不变量证明

对任意 \(Q\in O(3)\)，证明范数、点积和距离不变。指出证明是否需要 \(\det Q=1\)。

## Q15-05 极向量与轴向量

从 Levi--Civita 张量或一个反演例子推导

\[
(Qu)\times(Qv)=\det(Q)Q(u\times v).
\]

说明只测 \(SO(3)\) 为什么不足以区分极向量和轴向量。

## Q15-06 二阶张量

若 \(T=uv^{\mathsf T}\)，推导 \(T'=QTQ^{\mathsf T}\)。证明迹和 Frobenius 范数不变。给出“只左乘 \(QT\)”的一个失败性质。

## Q15-07 周期边

对

\[
d_{ijn,\mathrm{row}}=(f_j+n-f_i)A,
\]

推导主动旋转后的位移。说明旋转时 \(f_i,f_j,n\) 和完整 edge key 是否改变，以及节点换胞为何是不同操作。

## Q15-08 置换与旋转

节点向量特征以 \(X\in\mathbb R^{N\times3}\) 行存储。写出节点置换 \(P\) 与主动旋转 \(R\) 的作用，并证明两者交换。说明该证明为什么仍不能让置换测试替代旋转测试。

## Q15-09 数值门控设计

设计一个最小随机旋转测试，至少包含：

- 旋转 validator；
- 群律；
- 一个标量、一个极向量、一个轴向量和一个二阶张量；
- float64/float32 阈值；
- 两个强制失败入口。

说明为什么零向量、各向同性张量和同轴旋转不适合作为唯一夹具。

## Q15-10 综合审计题

某程序声称其周期图 Hamiltonian 输出“旋转不变”，证据是：

1. 所有边距离在 20 个随机旋转后不变；
2. 节点置换测试通过；
3. 预测矩阵的 Frobenius 范数不变；
4. 使用了名称含 equivariant 的库。

逐项判断这些证据能推出什么、不能推出什么。给出一个足以验证 Hamiltonian 轨道块协变的改进门控，要求包含对象定义、左右作用、边身份、轨道顺序、群律、dtype/容差和失败样例。
