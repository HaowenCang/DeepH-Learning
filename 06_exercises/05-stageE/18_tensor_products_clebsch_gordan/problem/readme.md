# 第 18 章练习

本题集覆盖 C-E05 的 CG 耦合能力，并连接 D-E04/D-E06/D-E09 与后续 T-E05/T-E08/T-E10。所有题均采用 DLMF/Condon--Shortley 相位、\(m_2\) 快轴、输出 \(L,M\) 递增的阶段 E 统一约定。

## Q18-01 张量积维数与索引

对 \(\ell_1=2,\ell_2=1\)：

1. 写出乘积维数和允许 \(L\)；
2. 验证输出维数之和；
3. 写出 \(m_2\) 快轴列索引 \(a(m_1,m_2)\)；
4. 计算 \(a(-2,-1)\)、\(a(0,1)\) 和 \(a(2,0)\)；
5. 说明为什么 shape 正确不能证明 Kronecker 轴顺序正确。

## Q18-02 选择定则与 CG--\(3j\)

写出本项目的 CG--\(3j\) 关系，并判定下列系数是否必为零：

\[
C^{20}_{1\,1,1\,-1},\quad
C^{21}_{1\,1,1\,-1},\quad
C^{30}_{1\,0,1\,0},\quad
C^{1,-1}_{1\,0,1\,-1}.
\]

对可能非零者给出理由；不要求在本题计算全部数值。

## Q18-03 构造 \(1\otimes1\) 的三个 \(M=0\) 行

在乘积子空间

\[
\{|1,-1\rangle|1,1\rangle,\ |1,0\rangle|1,0\rangle,\ |1,1\rangle|1,-1\rangle\}
\]

中，写出规范的 \(|0,0\rangle\)、\(|1,0\rangle\)、\(|2,0\rangle\)。验证三行两两正交、范数为一，并指出三个冻结相位锚点中哪一个直接约束每行。

## Q18-04 正交、完整性与 intertwiner

令 \(C\) 为完整 \(1\otimes1\) 规范矩阵。分别解释

\[
CC^{\mathsf T}=I,
\qquad
C^{\mathsf T}C=I,
\qquad
C(D^{(1)}\otimes D^{(1)})
=(1\oplus D^{(1)}\oplus D^{(2)})C
\]

各自验证什么。说明为什么只检查行范数、只检查三个锚点或只检查 \(R_z\) 都不足以通过 T-E05。

## Q18-05 输入交换与宇称

对两个类型均为 \((1,-1)\) 的极向量：

1. 写出 \(1\otimes1\) 的交换相位；
2. 判断 \(L=0,1,2\) 通道在输入交换下的对称性；
3. 写出三条输出的 \((L,p)\)；
4. 解释为什么 \(L=1\) 输出是轴向量，以及仅做 \(SO(3)\) 测试会遗漏什么。

## Q18-06 合法通道相位与错误局部相位

从规范矩阵 \(C\) 构造：

- 变异 A：整个 \(L=2\) 块乘以 \(-1\)；
- 变异 B：只把 \(L=2,M=0\) 行乘以 \(-1\)；
- 变异 C：只翻 \(C^{20}_{1\,0,1\,0}\)。

逐项判断规范表、正交/完整性和一般轴 intertwiner 是否应通过，并说明测试报告应如何表述，避免把合法基自由误判为数学错误。

## Q18-07 实笛卡尔三通道

取

\[
u=(1,0,1)^{\mathsf T},
\qquad
v=(0,2,1)^{\mathsf T}.
\]

计算：

1. 规范 \(L=0\) 输出 \(-u\cdot v/\sqrt3\)；
2. \(u\times v\)；
3. 对称无迹张量

\[
Q=\frac12(uv^{\mathsf T}+vu^{\mathsf T})
-\frac{u\cdot v}{3}I;
\]

4. 验证 \(Q\) 对称且无迹；
5. 写出冻结规范下 \(L=2\) 直接 CG 输出与实 STF 分量 \(q_a=\operatorname{tr}(B_a^{\mathsf T}Q)\) 的精确等式，并说明为何不允许按样例拟合比例或相位。

## Q18-08 multiplicity、路径和裁剪

输入 A 有 \(n_1=3\) 个 \((1,-1)\) 副本，输入 B 有 \(n_2=2\) 个 \((2,+1)\) 副本。

1. 写出允许输出 \((L,p)\)；
2. 计算每个 \(L\) 的原始路径 multiplicity 和全部路径数；
3. 若只保留 \(L=1,3\)，说明等变性、完整性和表达力应怎样分别表述；
4. 列出路径 provenance 的最小字段；
5. 写出 \(1\otimes2\) 的 \(L=1,2,3\) 三个最高 \(M=L\) 规范行，验证其范数，并给出 \(1\otimes2\leftrightarrow2\otimes1\) 的逐通道交换相位和一个一般轴验证入口。

## Q18-09 门控与失败非线性

先区分偶标量 \(g_+:(0,+1)\) 与伪标量 \(g_-:(0,-1)\)。证明偶标量对任意 \((\ell,p_x)\) 特征的门控

\[
y^{(\ell)}=g x^{(\ell)}
\]

保持原 \(O(3)\) 类型，并写出一般 \(g:(0,p_g)\) 门控的输出宇称。说明伪标量经奇函数、偶函数和 \(\sigma(s)=1+s\) 后各有什么宇称结果。随后用

\[
u=(1,2,0)^{\mathsf T},
\qquad R=R_z(\pi/2)
\]

计算逐分量平方 \(f(u)\)、\(f(Ru)\) 和 \(Rf(u)\)，给出失败残差。说明 T-E07/T-E08/T-E12 与图批处理还必须检查哪些宇称、身份和 mask 条件。

## Q18-10 端到端材料与测试合同

为一条“发送节点 \((\ell_{\mathrm{in}},p_{\mathrm{in}})\) 特征 + 边方向球谐 \((\ell_f,p_f)\) + 径向标量 \(\to\) 输出 \(L\)”消息路径写出：

1. 数学 contraction 和输出宇称；
2. 完整 edge identity、shell/multiplicity、CG 表与 component provenance；
3. mask/padding 处理顺序；
4. T-E05、T-E07、T-E08 与 T-E12 必须实际执行的正确检查和至少六类失败注入，其中必须包含 \(z^{(2)}=K_2q\) 的错误比例/局部相位及伪标量 \(1+s\)；
5. D-E09/T-E10 的 MAC、FLOP、聚合加法、数组 total/peak 与 wall-time 边界；
6. M8 前禁止外推或执行的事项。

答案应形成唯一可实现合同，不能只列架构名称或“检查等变性”。
