# 第 16 章练习：问题

## Q16-01 表示与忠实性

定义群的线性表示、表示的核和忠实表示。证明 \(D^{(0)}(R)=1\) 是 \(SO(3)\) 的合法表示，并说明它为何不忠实。解释不忠实为何不妨碍标量不变映射满足等变关系。

## Q16-02 不变子空间、直和与 multiplicity

定义不变子空间和不可约表示。对

\[
D(R)=1\oplus R\oplus R
\]

写出总维数、不可约类型和 multiplicity。说明两个向量副本之间允许什么形式的无几何输入线性混合。

## Q16-03 实 \(p\) 表

在顺序 \((p_x,p_y,p_z)\) 下写出 \(D^p(R_z(\pi/2))\)，逐列解释三个输入基函数的像。若外部顺序为 \((p_y,p_z,p_x)\)，写出与项目顺序之间的置换相似变换。

## Q16-04 \(d\) 基的正交归一性

写出冻结的五个 \(B_a\)。验证它们对称、无迹，并至少显式计算 \(B_{xy}\) 与自身、\(B_{x^2-y^2}\) 与 \(B_{3z^2-r^2}\)、两个不同非对角基之间的 Frobenius 内积。

## Q16-05 \(d\) 表推导

从

\[
T=\sum_b c_bB_b,
\qquad
T'=RTR^{\mathsf T}
\]

推导

\[
D^d_{ab}(R)
=\operatorname{tr}(B_a^{\mathsf T}RB_bR^{\mathsf T}).
\]

证明 \(D^d(R)\) 正交并满足正确复合顺序。

## Q16-06 五维数值锚点

对 \(R_z(\pi/2)\)，逐项计算五个 \(B_a\) 的像，组装冻结顺序下的 \(D^d\)。核对其正交性、行列式、迹，并用字符公式复核迹。

## Q16-07 \(O(3)\) 宇称

说明一般 \((\ell,p)\) 标签中的 \(p\) 与轨道宇称 \((-1)^\ell\) 的关系和区别。对空间反演比较 \(p\) 轨道、极向量和轴向量。解释为何只测 \(SO(3)\) 不能验证宇称。

## Q16-08 多壳层维度与成本

对 \((m_0,m_1,m_2)=(3,2,2)\) 和 \((5,4,3)\)，分别计算：

- 总表示维数；
- 同型自映射的自由参数数；
- float64/float32 单节点裸特征字节；
- 固定 \(N=4\) 与 \(N=7\) 时的节点值数组字节。

说明这些数字为何不是完整图消息层的 total 或 peak。

## Q16-09 非正交基失败分析

令 \(C_1=2B_{xy}\)，其余 \(C_a=B_a\)。若仍定义

\[
\widetilde D_{ab}(R)
=\operatorname{tr}(C_a^{\mathsf T}RC_bR^{\mathsf T}),
\]

计算 \(\widetilde D(I)\) 及其相对 \(I_5\) 的归一化 Frobenius 残差。判断“非正交基不能承载表示”是否由该失败推出，并给出正确修复方向。

## Q16-10 综合表示审计

某外部数组声称按 \(d\) 轨道变换，但只提供：

1. shape 为 \(5\times5\)；
2. 100 个随机旋转上矩阵近似正交；
3. 总轨道维数与项目相同；
4. Hamiltonian 的 Frobenius 范数在旋转前后相同。

逐项说明这些证据能推出什么、不能推出什么。设计一个足以接入阶段 E 的审计门控，至少覆盖基函数定义、顺序/相位、单位元、群律、\(R_z(\pi/2)\) 锚点、宇称、多壳层身份、Hamiltonian 左右作用、dtype/容差和失败样例。
