# 第 9 章练习参考解答

## Q9-01

\(H_{ab}(R)=\langle\phi_{a0}|\hat H|\phi_{bR}\rangle\)，\(S_{ab}(R)=\langle\phi_{a0}|\phi_{bR}\rangle\)。每块为 \(M\times M\)，\(H\) 具有能量单位，\(S\) 无量纲。必须登记晶格矢方向、轨道排序、轨道相位、单位、原胞和 Fourier 约定；缺少任一项都可能把不同表示误当成同一数据。

## Q9-02

复共轭并用 Hermiticity：

\[
H_{ab}(R)^*=\langle\phi_{bR}|\hat H|\phi_{a0}\rangle
=H_{ba}(-R).
\]

故 \(H(R)^\dagger=H(-R)\)，\(S\) 同理。非零块的伴随位于负平移；只转置遗漏复共轭，只复共轭遗漏指标交换。

## Q9-03

\[
H(k)=\sum_Re^{ikR}H(R),\qquad S(k)=\sum_Re^{ikR}S(R).
\]

用 \(H(R)^\dagger=H(-R)\) 重标记可得 \(H(k)^\dagger=H(k)\)，\(S\) 同理。正定性需检查 \(\lambda_{\min}(S(k))>0\) 或 Cholesky 成功；Hermitian 不排除负或零特征值。

## Q9-04

\(H,S,C\in\mathbb C^{M\times M}\)，\(E\) 为 \(M\times M\) 实对角矩阵，满足

\[
HC=SCE,\qquad C^\dagger SC=I.
\]

残差为 \(\|Hc-E Sc\|_2/[(\|H\|_2+|E|\|S\|_2)\|c\|_2]\)。简并子空间内可作任意 \(S\)-幺正混合，故应比较投影或子空间角度。

## Q9-05

近似矩阵束作用于精确向量：

\[
(H+\Delta H)c-E(S+\Delta S)c
=(\Delta H-E\Delta S)c.
\]

前向误差还受 \(S\) 条件数、谱隙、简并和带匹配影响；矩阵范数只给出输入扰动规模，不是无条件逐带保证。

## Q9-06

\[
H(R)=\frac1N\sum_ke^{-ikR}H(k),
\qquad
S(R)=\frac1N\sum_ke^{-ikR}S(k).
\]

本征值不包含本征矢和基规范；许多不同矩阵具有同一谱。因此只有能带一般不能唯一恢复矩阵块。

## Q9-07

成对截断改变 \(H(R),S(R)\) 的函数内容，但可保持 Hermiticity；减少 \(k\) 点改变采样集合。增加同一截断模型的采样密度只逼近截断后函数，无法重建已置零的块。

## Q9-08

\[
\bar H=U^\dagger HU,
\quad\bar S=U^\dagger SU,
\quad\bar C=U^{-1}C
\]

直接给出 \(\bar H\bar C=\bar S\bar CE\)、\(\bar C^\dagger\bar S\bar C=I\)。对任意试探对 \((E,c)\)，若 \(r=Hc-ESc\)，则 \(\bar r=\bar H\bar c-E\bar S\bar c=U^\dagger r\)。这保证精确本征对仍有零残差，却不保证 Q9-04 的 Euclidean 归一化残差数值不变。

例如取 \(H=\operatorname{diag}(0,2)\)、\(S=I\)、\(E=0\)、\(c=(1,1)^T\) 和非 unitary 的 \(U=\operatorname{diag}(0.1,1)\)。原归一化残差为 \(1/\sqrt2\approx0.70710678\)，同步变换后 \(\bar c=U^{-1}c\)，归一化残差为 \(1/\sqrt{101}\approx0.09950372\)。若 \(U\) 为 unitary，则相关 2-范数均不变，故该标量才保持不变。只变行破坏 Hermiticity，只变 \(H\) 改变矩阵束，错误系数方向改变抽象态。

## Q9-09

例题给出

\[
E(0)\approx(-0.73728885,0.76771829),
\qquad
E(\pi)\approx(0.96124921,1.75714114).
\]

对应 \(S\) 的特征值均为正；全路径最小值约 \(0.8479\)。忽略 \(S\) 后全路径最大能量差约 \(0.17994\)，说明普通谱不是同一问题。

## Q9-10

固定 Python 3.12.13、NumPy 2.3.5、SciPy 1.18.0 的复算结果为：全路径最大 \(H\) 与 \(S\) 反 Hermitian Frobenius 残差分别约为 \(1.69\times10^{-16}\) 与 \(1.63\times10^{-17}\)，最小 \(S\) 特征值为 \(0.84793196\)，最大逐本征对归一化 2-范数残差约为 \(6.40\times10^{-16}\)，最大 \(S\)-正交 Frobenius 残差约为 \(1.3\times10^{-15}\)，已知块逆变换误差低于 \(5\times10^{-14}\)。

128 点截断能带差约 \(0.16135>0.1\)，忽略 \(S\) 的最大差约 \(0.17994>0.1\)，缺少 \(-2\) 块的 Hermiticity 残差约 \(0.13797>10^{-2}\)，同步规范谱差低于 \(10^{-12}\)，单边规范差高于 \(10^{-3}\)。所有负例必须用断言而非仅打印。

## 错误诊断汇总

| 现象 | 机制 | 修复 |
|---|---|---|
| 非零块被强制自身 Hermitian | 混淆 \(R\) 与 \(-R\) 配对 | 检查 \(H(R)^\dagger=H(-R)\) |
| 能带与参考差异大 | 可能遗漏 \(S\)、排序或规范 | 分别核对对象、约定和残差 |
| 增加 \(k\) 点后截断误差不消失 | 采样不能恢复被删块 | 扩大实空间范围并成对恢复 |
| 重厄米化后错误“消失” | 数据缺陷被平均隐藏 | 先报告反 Hermitian 残差和缺块 |
