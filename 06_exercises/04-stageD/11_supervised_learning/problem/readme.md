# 第 11 章练习：题目

## Q11-01 对象与划分职责

给出监督回归样本三元组的定义，并说明训练、验证、测试各自允许参与的操作。解释为何固定随机种子不能替代独立测试集。

## Q11-02 结构组泄漏

样本组依次为 `A,A,A,B,B,C,C,C,D,D`。某逐帧划分把第 1、4、6、9 个样本放入测试，其余放入训练。列出训练/测试组集合，判断是否泄漏。再给出一个以组为单位且测试组恰为 \(\{D\}\) 的划分。

## Q11-03 MSE 梯度

对

\[
L(w,b)=\frac1M\lVert Xw+b\mathbf1-y\rVert_2^2,
\]

用矩阵微分推导 \(\nabla_wL\) 与 \(\partial L/\partial b\)。说明若损失改为 \(\frac1{2M}\lVert\cdot\rVert^2\)，梯度如何改变。

## Q11-04 tanh 反向传播

对

\[
Z=XW+\mathbf1b^\mathsf T,\quad
H=\tanh Z,\quad
\widehat y=Hv+c\mathbf1
\]

及平均 MSE，写出 \(\delta_y,\delta_Z,\nabla_WL,\nabla_bL,\nabla_vL,\partial L/\partial c\)，并标注形状。

## Q11-05 固定步长稳定性

设二次目标 Hessian 特征值为 \(1,4,10\)。分别判断 \(\eta=0.05,0.19,0.2,0.25\) 是否严格收敛；对收敛者给出迭代矩阵谱半径。

## Q11-06 有限差分

解释中心有限差分为何不能使用任意小的 \(h\)。给出一个四点步长扫描方案，并定义对近零梯度稳定的相对误差分母。

## Q11-07 预处理与早停

指出下列流程中的所有泄漏：先用全数据均值/方差标准化；每轮查看测试误差；选测试误差最低的轮次；最后再次报告同一测试误差。给出正确流程。

## Q11-08 聚合层级

结构 A 有 2 条边，平方误差分别为 1、1；结构 B 有 8 条边，平方误差均为 0.25。计算逐元素 MSE 和逐结构等权 MSE，并解释两者差异。

## Q11-09 泄漏随机效应模型

在 D-D02 的模型中，定义 \(\delta_g=\widehat b_g-b_g\) 和均方误差 \(\tau_g^2=\mathbb E[\delta_g^2]\)。取 \(\sigma_b^2=4\)、\(\tau_g^2=0.5\)、\(\sigma_\varepsilon^2=1\)，并假设测试噪声分别与 \(\delta_g\) 和新组 \(b_g\) 不相关。忽略公共斜率估计误差，比较逐帧已见组和全新组的期望平方误差；说明若不相关条件失效，公式需要增加什么项。
