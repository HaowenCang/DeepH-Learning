# 阶段 D 综合练习：题目

## 作答与验证口径

C-D01—C-D10 覆盖监督学习、分组评价、解析梯度、周期有向多重图、普通 MPNN、边级轨道 provenance、批处理、复杂度与授权边界。材料建设模式不要求学习者提交闭卷答案；每题仍必须具备完整参考解答、可执行验证入口和失败样例。

除非题目另行说明，采用行晶格、receiver-first 有向边与 `float64` 核心几何。任何数值结论均应同时说明成立条件、容差和不能推出的结论。

## C-D01 分组划分、泄漏与评价对象

合成数据有 12 个结构组，每组 6 帧，结构组 ID 为 0—11。指定 train 为 0—7，validation 为 8—9，test 为 10—11。

1. 写出三组的样本数及两两 group-ID 交集，并说明该划分验收什么。
2. 若改为对 72 帧逐帧随机划分，构造一种使每个结构组同时出现在 train 和 test 的划分，说明即使显式 group-ID 列没有作为模型输入，为什么仍可能产生泄漏。
3. 讨论下列预处理分别应在哪里拟合：特征标准化、按结构组计算的均值、标签标准化、早停阈值。指出哪些操作会污染 test。
4. 给出至少四项可执行失败检查，并说明“group ID 无交集”为什么仍不是无泄漏的充分条件。

## C-D02 masked MSE、完整反传与故障矩阵

设边级预测 \(\widehat y\in\mathbb R^{E\times P_{\max}}\)、标签 \(y\) 与布尔 mask \(m\)，有效分量数 \(S=\sum_{e,p}m_{ep}>0\)，损失为

\[
\mathcal L=\frac1S\sum_{e,p}m_{ep}(\widehat y_{ep}-y_{ep})^2.
\]

普通 MPNN 采用同步消息、receiver scatter-add、tanh 激活和边读出。

1. 推导 \(\partial\mathcal L/\partial\widehat y\)，说明 inactive padding 的梯度为何必须严格为零。
2. 沿边读出、tanh、receiver/sender gather 与 scatter-add 写出反传对象链；不要求展开特定权重矩阵的每个元素，但必须说明重复端点如何累加。
3. 设计中心差分检查，给出步长、误差定义、检查范围和通过阈值。
4. 对“漏掉 \(1/S\)”“把 receiver scatter 写成 sender scatter”“把 tanh 导数写成 1”“padding 梯度泄漏”“输出梯度符号翻转”五种实际错误分别说明为何可能 shape 正确，以及如何形成强制失败证据。

## C-D03 分组生成式、训练证据与独立组泛化

冻结生成式为

\[
x_{g,t}=[u_g,\tau_t]^\mathsf T+\xi_{g,t},\qquad
y_{g,t}=1.5u_g-0.7\tau_t+b_g+\varepsilon_{g,t},
\]

其中 `xi_std=0.005`、`bias_std=0.03`、`epsilon_std=0.002`。配置 A 为 12 组、每组 6 帧、2 层、隐藏宽度 3、边宽度 2、输出宽度 4、500 步、学习率 0.08、seed 20260806；配置 B 为 15 组、每组 5 帧、3 层、隐藏宽度 4、边宽度 3、输出宽度 4、700 步、学习率 0.06、seed 20260817。

1. 说明为什么 \(b_g\) 同时使逐帧泄漏更危险、又使新结构组评价必要。
2. 为 T-D03 写出充分的通过条件：训练轨迹、test MSE 绝对阈值、零预测基线比例、MSE/MAE、组集合和样本计数。
3. 说明“训练损失下降”“逐帧划分误差更低”“test MSE 小于 0.02”各自单独为何不足。
4. 实际运行 A/B CLI，记录规范 stdout 的 SHA-256、退出码与 T-D03 关键字段；再解释错误 seed 为什么必须被拒绝。

## C-D04 节点置换、边行重排与完整 provenance

主夹具的首条边为

\[
(i,j,n)=(0,1,(-1,0,0)),\quad
d=(-0.81,0.20,0.19),
\]

其 structure ID 为 `stageD-main`。设节点旧编号到新编号的置换为

\[
\pi(0)=2,\quad\pi(1)=0,\quad\pi(2)=3,\quad\pi(3)=1,
\]

随后独立倒序排列所有边行。

1. 写出该边的新端点、shift、位移与完整键；说明哪些字段只搬移，哪些字段必须重算。
2. 默认轨道表令节点 \(k\) 有 \(1+k\bmod2\) 个有序合成轨道。写出该边变换前后的 block shape、有效局部下标和实际轨道 ID 的解析规则。
3. 给出从变换前输出到变换后输出的双射验证算法。算法必须覆盖 prediction、完整键、edge ID、mask、block shape、局部下标与实际轨道 ID。
4. 构造至少五个“数值看似合理但身份错误”的失败样例，并说明普通节点置换等变性为什么不推出三维旋转等变性。

## C-D05 周期代表变换与 \(K_q\) 双射

继续使用 C-D04 的首条边。令

q_0=(1,-1,0),\qquad q_1=(-2,0,1).

1. 计算变换后 shift \(n'=n+q_i-q_j\) 与回拉 shift。
2. 代数证明分数位移与笛卡尔位移不变，并计算错误保持 \(n'=n\) 时的分数位移误差。
3. 写出边键映射 \(K_q\) 和逆映射；说明公共换胞与逐原子换胞测试的关系。
4. 设计包含排序变化、等距多镜像边和轨道块输出的 T-D05 验证流程，明确为什么不能按原行号、距离或仅按原子对配对。

## C-D06 斜晶胞镜像界、完备性与最小镜像失败

1. 从 \(d=(f_j+n-f_i)A\) 推导

   \[
   |n_k|<r_c\lVert A^{-1}_{:k}\rVert_2+1
   \]

   以及安全整数盒 \(M_k=\lceil r_c\lVert A^{-1}_{:k}\rVert_2+1\rceil\)。
2. 对主夹具 \(N=4\)、bounds \((2,2,2)\) 计算候选数，并计算外扩一层后的候选数。说明完备性测试比较什么，而不是比较什么。
3. 构造一原子正交晶胞 \(A=\operatorname{diag}(0.4,5,5)\)、\(r_c=1\)，列出沿第一晶格方向的保留自镜像，并证明固定 `[-1,1]^3` 漏边。
4. 说明条件数阈值 \(\kappa_2(A)<10^8\)、`float64` 与有限正 cutoff 的作用和边界；给出最小镜像失败但全枚举成功的判据。

## C-D07 多重边、自镜像与唯一身份

\[
A=\operatorname{diag}(1,5,5),\qquad
F=\begin{bmatrix}0.25&0&0\\0.75&0&0\end{bmatrix},\qquad
r_c=1.
\]

1. 枚举全部保留的有向边 \((i,j,n)\)，按跨原子边与非零自镜像分类，并给出总边数。
2. 说明零 shift 自环的处理。比较按 \((i,j)\) 去重、按距离去重和每对只保留一个最小镜像三种错误策略的丢边结果。
3. 为每条边定义完整键与规范 SHA-256 输入。说明“ID 唯一”为什么仍不能替代几何和 provenance 验证。
4. 设计至少六项针对多重边、端点、shift、ID、block shape、mask 和轨道身份的失败注入。

## C-D08 同步感受野、异步穿透与聚合边界

考虑有向链 \(0\to1\to2\to3\)，按 receiver-first 记为边 \((1\leftarrow0)\)、\((2\leftarrow1)\)、\((3\leftarrow2)\)。初始只扰动节点 0。

1. 分别写出 1、2、3 层同步局部消息后可能受影响的节点集合，并用有向前驱距离证明一般结论。
2. 若在一层循环中按节点 1、2、3 顺序原地写回，说明扰动为何可在一层到达节点 3。
3. 比较 sum、mean、max 对空入边的合格策略；说明 `has_incoming` 的用途。
4. 列出至少四个会使 \(L\) 层感受野结论失效或需修改的架构条件，并区分“结构上可达”与“数值上实际非零影响”。

## C-D09 concat/padded 批、NaN 隔离与端到端追踪

把主夹具 \((N,E)=(4,18)\) 与 C-D07 夹具 \((2,8)\) 组成一个 batch。设节点特征宽度 \(d=3\)、边特征宽度 \(d_e=3\)、\(P_{\max}=4\)。

1. 写出 concat 形式中总节点数、总边数、第二图节点 offset、全局端点变换、`node_graph_id`/`edge_graph_id` 形状，以及核心张量 shape。
2. 写出 padded 形式的 \(B,N_{\max},E_{\max},P_{\max}\) 和核心张量 shape；给出第二图 inactive node/edge 区域及端点哨兵规则。
3. 说明为什么 inactive padding 可包含 NaN 或 \(10^{300}\)，但切片必须发生在 gather、统计、归一化、前向与 loss 之前。设计三运行残差检查。
