## A13-03

## A13-04

基步 \(L=0\) 时只依赖自身。归纳假设第 \(L\) 层状态只依赖 \(L\) 步前驱；下一层只读取自身和直接 sender 的第 \(L\) 层状态，所以依赖集合是自身 \(L\) 步前驱与每个直接前驱的 \(L\) 步前驱之并，即 \(L+1\) 步前驱。边输出读取 \(i,j\) 两端点，因此依赖集合是 \(\mathcal N^-_L(i)\cup\mathcal N^-_L(j)\)。

## A13-06

强夹具应随机置换节点，随之重标 receiver/sender；随机重排边行，随之重排 shift、边特征、edge ID、mask、标签和 provenance；节点特征应非对称，图应含方向和多重边。比较每层节点状态的逆置换残差、边输出按完整键配对后的残差以及 provenance。只比较图级 sum 会消除节点顺序，可能掩盖边端点连接错误和节点状态互换。

对给定 \(2\times2\) 块，展平位置与身份解析为：

| (a) | \((\alpha,\beta)\) | 实际轨道对 |
|---:|---:|---|
| 0 | \((0,0)\) | `('r0','s0')` |
| 1 | \((0,1)\) | `('r0','s1')` |
| 2 | \((1,0)\) | `('r1','s0')` |
| 3 | \((1,1)\) | `('r1','s1')` |

validator 必须对每个有效位置重算

\[
(\texttt{orbital\_i\_id},\texttt{orbital\_j\_id})
=
(\texttt{node\_orbitals}[0][\alpha],
\texttt{node\_orbitals}[1][\beta]).
\]

若只保留 \((\alpha,\beta)\)，遗漏两端有序轨道表，就不能恢复实际身份。若把 receiver 表交换为 `['r1','r0']`，却保持局部下标和已缓存实际 ID 不变，则 (a=0) 的重算结果变为 `('r1','s0')`，与缓存的 `('r0','s0')` 不同，必须失败。表与错误端点绑定时同理。padding 位置还必须同时满足 mask=false、局部下标 (-1)、实际 ID 为空字符串。排序、批处理和逆置换时，预测、完整边键、mask、两类下标/身份及轨道表引用必须同步映射。

## A13-09

应注入：

- 漏掉 \(1/S\)，梯度整体尺度错误；
- 把 receiver scatter 改为 sender，梯度流向错误节点；
- 把 \(1-\tanh^2z\) 写成 \(1-\tanh z\)；
- 未将 padding 输出梯度置零。

总损失仍可能下降，因为错误梯度可能与下降方向部分相关，或模型可用其他参数补偿。有限差分和定向支持断言才能定位这些结构性错误。

## A13-10

距离 \(r=\lVert d\rVert\) 在刚体旋转下不变；笛卡尔位移分量随旋转矩阵混合。只用距离可给标量网络旋转不变输入，但轨道块需要按非平凡轨道表示变换；直接使用位移的普通 MLP 也没有受控等变律。因此轨道块协变必须由阶段 E 推导与随机旋转测试验证。
