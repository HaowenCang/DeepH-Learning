# 第 13 章练习：题目

## Q13-01 前向张量形状

给定 \(N=5,E=12,d=4,d_e=3,P_{\max}=6\)，写出 \(H,Z_m,M,A,Z_u,G,\widehat Y\) 的形状，以及各权重矩阵的形状。

## Q13-02 receiver/sender 方向

对单边 \(1\to0\)，消息只取 sender 状态，更新为 self 加消息。取 \(h_0=1,h_1=3\)，计算正确结果和把 receiver/sender 互换后的结果。

## Q13-03 同步与原地更新

## Q13-04 感受野证明

## Q13-05 masked MSE

两条边、\(P_{\max}=3\)，mask 分别为 \((1,1,0)\)、\((1,0,0)\)，残差分别为 \((1,-2,9)\)、\((3,8,7)\)。计算逐有效元素 MSE 和对预测的梯度。

## Q13-06 置换测试

说明一个强 T-D04 夹具应同时随机化哪些对象，并比较哪些输出。为什么只比较图级 sum 不充分？

再取一条 `receiver=0, sender=1`、`block_shape=(2,2)` 的边，令两端有序合成轨道 ID 表分别为 `['r0','r1']` 和 `['s0','s1']`。按行优先列出四个有效位置的局部下标与实际轨道对。说明为什么“局部下标和 mask 正确，但遗漏轨道表、交换表内顺序，或使轨道表与端点不一致”必须由 validator 拒绝。

## Q13-07 复杂度与内存

## Q13-08 损失聚合层级

## Q13-09 梯度失败注入
