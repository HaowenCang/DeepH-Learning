# 第 12 章练习：参考解答

## A12-01

最低 schema 为：

| 字段 | dtype | 形状 |
|---|---|---|
| `node_features` | float64 | \((4,5)\) |
| `receiver` | int64 | \((7,)\) |
| `sender` | int64 | \((7,)\) |
| `shift` | int64 | \((7,3)\) |
| `displacement` | float64 | \((7,3)\) |
| `distance` | float64 | \((7,)\) |
| `edge_features` | float64 | \((7,3)\) |

还需结构 ID、有限性、端点范围和距离—位移关系验证。

拼接 \(B\) 个图时，`node_graph_id` 为 int64 \((N_{\mathrm{tot}},)\)，`edge_graph_id` 为 int64 \((E_{\mathrm{tot}},)\)，取值在 \([0,B)\)。每条边必须满足

\[
\texttt{node\_graph\_id[receiver[e]]}
=\texttt{edge\_graph\_id[e]}
=\texttt{node\_graph\_id[sender[e]]}.
\]

端点分属不同 graph ID 会把两个独立结构错误连接，必须拒绝，即使端点都在总节点范围内。

## A12-02

反向边为

\[
(j,i,-n)=(0,2,(-1,1,0)).
\]

原边消息沿 \(0\to2\)，反向边沿 \(2\to0\)。若反向边仍使用 \(n\)，两条边的位移通常不再互为相反数。

## A12-03

第一和第二条可共存，因为 shift 不同；第三条与第一条完整键相同，是非法重复。按 \((i,j)\) 去重会把第二条合法周期镜像错误删除。

## A12-04

原边 \((0,2,n)\) 变为

\[
(p(0),p(2),n)=(1,0,n).
\]

按 \(P_{p(i),i}=1\)，

\[
P=
\begin{bmatrix}
0&0&1\\
1&0&0\\
0&1&0
\end{bmatrix}.
\]

邻接计数矩阵满足

\[
A'=PAP^\mathsf T.
\]

## A12-05

有限向量和对排列满足

\[
\sum_{r=1}^K m_{\pi(r)}
=\sum_{r=1}^K m_r.
\]

这只说明存储顺序不影响精确和；不能保证聚合对不同多重集合单射，也不能保证三维旋转等变。浮点实现还可能有归约顺序舍入差异。

## A12-06

- sum：\(\{1,1\}\) 与 \(\{2\}\) 都为 2；
- mean：\(\{1\}\) 与 \(\{1,1\}\) 都为 1；
- max：\(\{1\}\) 与 \(\{0,1\}\) 都为 1。

加入邻居计数可区分上述 mean 的两个集合，也可区分元素数不同的部分碰撞；但相同计数下仍可能有不同集合产生同一有限维统计量，因此不能保证全局单射。

空入边节点的 sum 为零向量；mean 使用 \(\sum m/\max(1,\deg_{\mathrm{in}})\) 也返回零，同时必须返回 `has_incoming=false`，防止把默认零误作观测均值。max 对空集合不定义，选择 max 时 validator 必须拒绝含空入边节点的图。

## A12-07

真实分量数为

\[
p_i p_j=3\times2=6,
\]

所以 8 位 mask 必须在且只在 \(a=0,\ldots,5\) 为 true，\(a=6,7\) 为 false。行优先公式为

\[
a=\alpha p_j+\beta.
\]

反解为

\[
\alpha=\left\lfloor a/p_j\right\rfloor,
\qquad
\beta=a\bmod p_j.
\]

对 \((2,1)\)，

\[
a=2\times2+1=5.
\]

在 \(\{0,1,2,5,6,7\}\) 为 true 的 mask 虽然数量为 6，但不是右侧连续 padding，无法按冻结 schema 唯一恢复块，必须拒绝。\(P_{\max}=5<6\) 无法容纳真实块，也必须拒绝。

## A12-08

规范 JSON 数组为

\[
[\texttt{"stageD-edge-v1"},
\texttt{structure\_id},i,j,n_x,n_y,n_z].
\]

使用 `ensure_ascii=false`、紧凑分隔符和 UTF-8 后取 SHA-256。浮点字符串依赖格式、舍入和容差；距离还会丢失方向，并可能让不同端点或不同镜像碰撞。因此匹配身份使用离散字段，位移/距离另作数值验证。

## A12-09

可能原因包括：

- 只置换节点特征，未重标边端点；
- receiver/sender 互换；
- 消息函数按节点绝对行号使用不同参数；
- 聚合依赖边行顺序；
- 边输出没有随边映射重排；
- 按 \((i,j)\) 去重导致多重边数量变化。

检测 receiver/sender 可用两节点单向边，令端点特征不同且消息只读取 sender；正确结果只改变 receiver。检测顺序依赖可给同一 receiver 两条数值不同的入边，交换边行，要求 sum 输出在容差内不变。

## A12-10

节点重编号等变是离散索引变换，第 12 章可通过同步置换和 D-D03/T-D04 验证。三维旋转等变涉及坐标与表示矩阵，属于阶段 E 的群表示和随机旋转门控。Hamiltonian 标签物理正确还依赖阶段 C 标签语义、M8 冻结的正式对象以及 M9 以后对矩阵性质和下游物理量的验证。第 12 章合成图通过不能授权 DeepH 安装或正式数据下载。
