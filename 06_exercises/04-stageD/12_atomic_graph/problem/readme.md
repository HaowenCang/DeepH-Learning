# 第 12 章练习：题目

## Q12-01 图对象与形状

给出一个 \(N=4,E=7,d_n=5,d_e=3\) 单图的最低张量 schema，写出 `node_features`、`receiver`、`sender`、`shift`、`displacement`、`distance`、`edge_features` 的 dtype 和形状。再写出拼接批的 `node_graph_id`/`edge_graph_id` 形状及逐边同图断言，并说明 receiver 与 sender 分属不同 graph ID 时为何必须失败。

## Q12-02 有向边与反向边

原边为 \((i,j,n)=(2,0,(1,-1,0))\)。写出对应反向边，并说明消息流方向。若反向边仍使用 \(n\)，哪个关系通常会失败？

## Q12-03 多重边与去重

判断以下三条边中哪些可共存，哪些构成完全重复：

\[
(0,1,(0,0,0)),\quad
(0,1,(1,0,0)),\quad
(0,1,(0,0,0)).
\]

说明为什么不能按 \((i,j)\) 去重。

## Q12-04 节点置换

给定 \(p(0)=1,p(1)=2,p(2)=0\) 和原边 \((0,2,n)\)，写出新边。构造置换矩阵 \(P\)，并写出邻接计数矩阵的变换式。

## Q12-05 求和聚合证明

证明对同一接收节点的入边行任意重排，精确算术中的 sum 聚合不变。列出该证明不能保证的两个性质。

## Q12-06 聚合碰撞

分别给出一对 sum 碰撞、一对 mean 碰撞和一对 max 碰撞的标量多重集合。解释加入邻居计数可能消除哪一类碰撞，但为什么仍不能保证全局单射。对空入边节点，写出阶段 D 的 sum/mean 行为、mean 的伴随 mask，以及 max 的 validator 行为。

## Q12-07 可变块 mask

某边端点轨道数为 \(p_i=3,p_j=2\)，\(P_{\max}=8\)。写出完整 mask 位置、行优先展平与反解公式，并求 \((\alpha,\beta)=(2,1)\) 的展平索引。判断在 \(\{0,1,2,5,6,7\}\) 为 true 的 mask 是否有效，并说明 \(P_{\max}=5\) 时的处理。

## Q12-08 edge instance ID

列出生成 `edge_instance_id` 的规范 JSON 字段。说明为什么 ID 不应直接由浮点位移字符串生成，以及为什么只用距离作为键会折叠不同边。

## Q12-09 失败诊断

某实现通过了数组形状测试，但置换后输出不一致。给出至少四个可能原因，并为其中两个设计能避免对称性掩盖的最小夹具。

## Q12-10 证据与授权边界

区分以下三项：节点重编号等变、三维旋转等变、Hamiltonian 标签物理正确。说明第 12 章能验证哪一项，后两项分别依赖什么后续门控。
