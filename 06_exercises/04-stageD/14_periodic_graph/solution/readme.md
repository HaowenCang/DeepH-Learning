# 第 14 章练习：参考解答

## A14-01

逐分量 floor 得

\[
q=(-1,1,0),
\qquad
f=\widetilde f-q=(0.75,0.5,0.5).
\]

按 row-vector 约定，

\[
r=fA
=(0.75,0.5,0.5)
\begin{bmatrix}2&0&0\\1&3&0\\0&0&4\end{bmatrix}
=(2,1.5,2).
\]

## A14-02

令 \(B=A^{-1}\) 和 \(x=f_j+n-f_i\)。由 \(d=xA\) 得 \(x=dB\)，所以

\[
|x_k|=|dB_{:k}|
\le\lVert d\rVert_2\lVert B_{:k}\rVert_2
\le r_c\lVert B_{:k}\rVert_2.
\]

又因规范坐标差的绝对值严格小于 1，

\[
|n_k|<r_c\lVert B_{:k}\rVert_2+1.
\]

向上取整得到安全有限界。证明只要求所有真边被包含，不要求每个盒内点都是真边，因此该界可以保守；盒内仍须用球形距离过滤。

## A14-03

单位晶格下距离等于 \(\lVert n\rVert_2\)。距离 1 的 shift 有 6 个：一个分量为 \(\pm1\)，其余为 0。距离 \(\sqrt2\) 的 shift 有 12 个：两个分量各为 \(\pm1\)，第三个为 0。因此共保留 18 条非零自镜像边。\(n=(0,0,0)\) 是零位移自环，排除；距离 \(\sqrt3\) 的 8 个角点超过 cutoff。

## A14-04

第一方向位移为

\[
d_x=0.75+n_x-0.25=0.5+n_x.
\]

要求 \(|0.5+n_x|\le0.6\)，整数解为 \(n_x=0,-1\)。由于第二、三晶格长度为 5，任何非零 \(n_y,n_z\) 都超出 cutoff。所以完整边恰为两个 shift \((0,0,0)\) 和 \((-1,0,0)\)，距离均为 0.5。按 \((i,j)\) 去重会合并两条物理边；单最小镜像会任意丢掉一条并引入 tie 依赖；按距离去重同样把等距但 shift 不同的边错误合并。

## A14-05

\[
n'=n+q_i-q_j
=(1,-1,0)+(2,0,-1)-(-1,3,1)
=(4,-4,-2).
\]

回拉为

\[
n^{\mathrm{can}}=n'-q_i+q_j=(1,-1,0)=n.
\]

并且

\[
f_j+q_j+n'-f_i-q_i=f_j+n-f_i.
\]

若错误保持 \(n'=n\)，变换后分数位移比基线多 \(q_j-q_i=(-3,3,2)\)，笛卡尔位移误差为

\[
(q_j-q_i)A.
\]

## A14-06

规范 JSON 为

```text
["stageD-edge-v1","cell-A",2,0,0,-1,2]
```

同一完整键出现两次意味着同一边实例被重复记录，必须拒绝。不同 shift 是不同周期镜像，即使端点或距离相同也必须保留。ID 之外仍应验证 float64 位移向量、距离、cutoff 成员资格、端点范围、整数 shift、block shape、mask、轨道身份和 schema 版本；换胞复核用回拉键精确配对后再以 `rtol=0, atol=1e-12` 比较位移与距离。

## A14-07

\(A_-\) 的条件数为 \(5\times10^7\)，严格小于阈值，接受；\(A_0\) 恰为 \(10^8\)，拒绝；\(A_+\) 为 \(2\times10^8\)，拒绝。条件数通过只限制相对奇异性；绝对很短的晶格方向或很大的 cutoff 仍会使

\[
M_k=\left\lceil r_c\lVert A^{-1}_{:k}\rVert_2+1\right\rceil
\]

很大。直接枚举候选上界为

\[
N^2\prod_{k=1}^3(2M_k+1).
\]

因此还需记录候选数、保留边数和构图时间。

## A14-08

由三角不等式，

\[
\left\lVert\sum_{\ell=1}^L d_{e_\ell}\right\rVert_2
\le\sum_{\ell=1}^L\lVert d_{e_\ell}\rVert_2
\le Lr_c.
\]

该求和要求在同一连续周期提升中选择相邻边镜像，使前一边的终点与后一边的起点代表一致；同时，MPNN 结论要求局部消息、同步更新、无跨图边，且初始特征未预编码全局结构、没有全局状态回灌。逆命题不成立，因为两个节点的几何距离虽小，离散图中仍可能没有长度不超过 \(L\) 的路径。“图结构可达”也不等于“数值上实际非零影响”，后者还受聚合碰撞、零权重和激活饱和影响。增大 cutoff 会改变单层边集和度分布；增加层数在固定边集上增加组合路径并提高网络成本；加密结构帧或 \(k\) 点采样改变的是数据或电子结构离散化。这些对象的验证标准不同。

## A14-09

夹具至少应含同一 \((i,j)\) 的 \(n=(0,0,0)\) 与 \((-1,0,0)\) 两条等距边，以及一个 \(i=j,n\ne0\) 的自镜像。每条边配 \(2\times2\) 块、连续 mask、局部轨道下标和非平凡有序合成轨道表。

应拒绝的变异包括：

- 删除 shift；
- 只按 \((i,j)\) 或距离去重；
- 重复完整边键或伪造 edge ID；
- 交换 receiver/sender 而不更新位移；
- mask true 数量正确但位置不连续；
- 轨道表顺序交换而逐分量实际 ID 未更新；
- block shape 与有效元素数不一致；
- padding 行进入损失或端点不是 \(-1\)。

排序、拼接批处理、节点置换逆映射和换胞回拉时，预测、端点、shift、位移、距离、完整键、edge ID、mask、块形状、局部下标、实际轨道身份和 schema 版本必须同步。逐原子换胞下先把 shift 回拉到规范键，再与基线配对。
