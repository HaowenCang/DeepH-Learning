# 第 14 章练习：题目

## Q14-01 行晶格与规范坐标

取

\[
A=\begin{bmatrix}2&0&0\\1&3&0\\0&0&4\end{bmatrix},
\qquad
\widetilde f=(-0.25,1.5,0.5).
\]

计算 \(q=\lfloor\widetilde f\rfloor\)、规范 \(f\) 和 \(r=fA\)。

## Q14-02 有限镜像界

从 \(d=(f_j+n-f_i)A\) 推导 \(|f_{jk}+n_k-f_{ik}|\le r_c\lVert A^{-1}_{:k}\rVert_2\)，并说明为什么 \(M_k=\lceil r_c\lVert A^{-1}_{:k}\rVert_2+1\rceil\) 给出完备但不必最紧的整数盒。

## Q14-03 自镜像枚举

单位立方晶胞中只有一个原子，\(r_c=\sqrt2\)。列出按冻结规则保留的非零自镜像 shift 数量，并按距离 1 与 \(\sqrt2\) 分类。说明零 shift 如何处理。

## Q14-04 多重边与最小镜像

对例 14-5 的晶胞和原子对，独立复算所有满足 cutoff 的第一方向 shift。说明只按 \((i,j)\) 去重、只保留一个最小镜像或按距离去重分别会造成什么错误。

## Q14-05 周期代表协变

设基线边 \(n=(1,-1,0)\)，\(q_i=(2,0,-1)\)，\(q_j=(-1,3,1)\)。计算 \(n'\) 和回拉 \(n^{\mathrm{can}}\)，并代数证明位移不变。再说明错误保持 \(n'=n\) 时位移误差是什么。

## Q14-06 完整键与边 ID

写出结构 `cell-A`、receiver 2、sender 0、shift \((0,-1,2)\) 的规范 JSON 数组。说明为什么完整键重复必须拒绝，而同一 \((i,j)\) 但不同 shift 或相同距离的边必须保留。列出 ID 之外仍需验证的数值字段。

## Q14-07 病态晶胞与成本

判断 \(A_-\)、\(A_0\)、\(A_+\) 是否进入枚举。对通过的晶格，说明为什么条件数通过仍不能保证候选镜像数小；给出直接枚举候选数的符号上界。

## Q14-08 cutoff 与层数

在局部消息、同步更新、无全局特征预编码或全局状态回灌的条件下，证明同一连续周期提升中 \(L\) 条 cutoff 边组成的路径，其端到端位移范数不超过 \(Lr_c\)。说明该上界的逆命题为什么不成立，并比较“图结构可达”“数值上实际非零影响”“增大 cutoff”“增加网络层数”和“加密结构或 \(k\) 点采样”这些不同对象。

## Q14-09 provenance 失败注入

设计一个包含同一原子对两个等距镜像、非零自镜像和 \(2\times2\) 合成轨道块的夹具。列出至少六种必须拒绝的 provenance 变异，并说明排序、批处理和换胞回拉时哪些数组必须同步。

## Q14-10 完整验证与授权边界

给出 T-D05—T-D07/T-D10 的最小验证矩阵：成功条件、至少四个定向失败样例和需要记录的成本字段；cutoff validator 必须分别覆盖 NaN、\(+\infty\)、\(-\infty\)、零与负数。最后说明 M6 当前允许的输入范围，以及进入 M8/M9 的两个停点。
